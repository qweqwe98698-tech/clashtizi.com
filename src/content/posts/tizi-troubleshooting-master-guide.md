## 五、常见高频问题解答 (FAQ)

### Q1：为什么节点列表全是红色的 Timeout，但浏览器打开 YouTube 却能正常播放？
**答**：这是极为典型的**测速机制误报**！客户端测速是向特定网址（如 `generate_204`）发包；若该测速网址受到临时干扰或被屏蔽，测试就会显示全红，但节点本身的海外网络链路完全正常。在设置中更换测速 URL 即可，红字完全不影响实际使用。

### Q2：为什么把梯子软件关掉之后，电脑连百度和微信都断网了？
**答**：属于经典的**系统代理残留**！客户端退出时未能成功注销注册表代理。按 `Win + I` 打开 Windows 设置 ──► 进入【网络和 Internet】──►【代理】──► 将“手动设置代理”下的【使用代理服务器】开关手动关闭即可秒级恢复。

### Q3：为什么 Global (全局模式) 能正常上网，切回 Rule (规则模式) 就打不开网页？
**答**：**这是网络完好、纯属分流规则问题的最高价值信号！** 常见原因包括：①该海外网站的域名未被规则库收录，被漏判为国内直连；②规则从上到下顺序写反，`GEOIP,CN` 抢先直连；③分流规则命中的策略组内部选到了超时失效的红色节点。

### Q4：为什么浏览器看视频非常流畅，但桌面版 Telegram 却一直转圈连不上？
**答**：因为 Windows 的“系统代理”仅适用于标准浏览器，Telegram 等独立应用默认不读取系统注册表代理。**在 Telegram 的网络连接设置中手动添加 SOCKS5 代理（地址 `127.0.0.1`，端口根据客户端填 `7897` 或 `10808`）**即可秒级解决；或者直接开启客户端的【TUN 模式】。

### Q5：为什么开启 TUN 模式时会提示权限不足或创建适配器失败？
**答**：**因为未以管理员身份运行！** 创建虚拟网卡属于 Windows 高危内核级操作，必须彻底退出客户端，在程序图标右键选择【以管理员身份运行】，再次开启即可顺利加载驱动。

### Q6：直接输入海外 IP 能打开网页，但输入域名就打不开怎么解决？
**答**：这 100% 证明底层网络代理通道完全正常，问题纯属**域名解析层阻断**！在客户端中配置规范的海外 DoH 加密 DNS（如 `https://1.1.1.1/dns-query`）或开启【Fake-IP 模式】即可秒级恢复。

### Q7：手机一锁屏息屏，为什么过几分钟代理就自动断开了？
**答**：这是移动操作系统（Android / iOS）的深度省电保护机制：系统在息屏后会自动冻结或杀灭后台高耗电应用以节省电量。在系统【设置】──►【应用管理】中将客户端的省电策略改为 **【无限制 (允许后台高耗电)】**，并在多任务后台给客户端加上“小锁”常驻即可。

### Q8：遇到未知代理网络故障，最忌讳的操作是什么？
**答**：最忌讳“病急乱投医盲目清空订阅、重装软件或重装操作系统”。对照本文的十层诊断模型与 5 分钟决策树，单变量逐层排查，任何疑难杂症都能在 3 分钟内精准定位并彻底解决！
