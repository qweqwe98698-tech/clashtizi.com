## 二、跨客户端免费节点批量导入实操大满贯

获取到一长串 `vless://` 或 Base64 订阅链接后，按以下标准步骤导入：

### 1. v2rayN (Windows) 批量导入实操
- 复制 Telegram 或 GitHub 网页上的所有节点文本（可同时包含几十条 `vmess://`、`vless://`、`ss://` 链接）；
- 切换到 v2rayN 主界面，直接按下键盘快捷键 **`Ctrl + V`**（或点击顶部菜单【服务器】──►【从剪贴板导入批量 URL】）；
- 瞬间成功导入几十个节点！
- 按下 **`Ctrl + S`**（批量测试真实连接延迟），鼠标右键按延迟排序，双击选中延迟最低的绿色节点即可！

### 2. Shadowrocket (小火箭) 导入实操
- 复制单节点链接或 Base64 订阅链接；
- 打开 Shadowrocket，App 会自动弹出【检测到剪贴板节点，是否添加？】提示，点击【添加】；
- 若未弹窗：点击右上角 **`+`** ──► 类型选择 **【Subscribe (订阅)】** ──► 在 URL 栏粘贴链接 ──► 点击右上角【完成】；
- 首页下拉刷新节点列表，点击【连通性测试】，挑选可用节点连接。

### 3. Clash Verge Rev 导入实操
- 由于 Clash 必须使用标准的 YAML 格式配置文件，普通 `vmess://` 字符串无法直接识别；
- 打开可靠的开源订阅转换工具（如在线 Subconverter）；
- 将免费节点链接粘贴进【订阅链接】，生成模式选择【Clash】；
- 复制生成的转换链接，粘贴进 Clash Verge Rev 的【订阅 (Profiles)】面板，点击【下载 / 导入】即可。

**答**：因为免费节点公开在网上后，短时间内会有数万人同时涌入连接，异常庞大的跨境加密并发流量会被防火墙在几小时内精准识别并直接阻断 IP，导致节点极速暴毙。

### Q3：如何将一串 `vless://` 或 `vmess://` 代码快速导入 v2rayN？
**答**：直接复制这一串代码（或批量复制多条），在 **[v2rayN](/v2rayn/)** 主界面按下快捷键 **`Ctrl + V`**，软件即可自动解析并批量导入到服务器列表中。

### Q4：为什么 Clash 无法直接导入 `vmess://` 字符串链接？
**答**：因为 Clash 仅支持结构化的 `.yaml` 格式配置文件。需要将单节点链接或 Base64 订阅链接复制进 **在线订阅转换工具 (Subconverter)**，生成 Clash 专用链接后再导入 **[Clash Verge Rev](/clash-verge-rev/)**。
