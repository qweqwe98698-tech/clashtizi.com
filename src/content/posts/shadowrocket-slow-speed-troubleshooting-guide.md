> **【💡 30 秒极速直接答案：Shadowrocket 速度慢核心定性与四大排障原则】**
> - **第一核心纠偏**：**“节点测速显示 25ms 绝不代表下载速度快！”** 连通性测试的毫秒数仅反映握手延迟 (Latency)。看 YouTube 4K 视频和大文件下载主要取决于节点的**物理带宽储备 (Bandwidth)** 与**跨境丢包率 (Packet Loss)**；
> - **六类典型“慢”现象极速对号入座**：
>   1. **网页秒开，但下载大文件极慢（仅几百 KB/s）** ──► 属于**带宽瓶颈或单线程限速**，换用带大带宽/高倍率标识的专线节点；
>   2. **测速显示几百兆，但刷视频频繁转圈卡死** ──► 属于**跨境公网海缆丢包严重**导致 TCP 拥塞重传，需切换至 IPLC/IEPL 内网专线；
>   3. **白天飞快，晚上 8 点后断崖式降速** ──► 典型的**晚高峰国际骨干网拥塞**，避开拥挤的热门香港 01 节点，改选冷门新加坡或台湾大带宽节点；
>   4. **国内微信和淘宝极其卡顿** ──► 属于**全局路由误切成了【代理 (Proxy)】**，切回【配置 (Config)】模式即可秒级复活；
>   5. **连家里 Wi-Fi 极慢，切手机 5G 流量瞬间飞快** ──► 纯粹是**本地 2.4GHz Wi-Fi 频段干扰或路由器散热不良**，与代理节点无关；
>   6. **绝大多数网站飞快，只有特定一个网站卡死** ──► 属于目标网站海外 CDN 边缘节点对当前出口 IP 限速，换其他国家节点即可。

## 一、六大典型“慢”现象分类与第一优先级排查对照表

在排查 Shadowrocket 速度前，请先明确你的手机到底遭遇了哪一种“慢”：

| 故障现象分类 | 核心制约物理维度 | 最核心真实诱发诱因 | 第一步标准应对动作 |
| :--- | :--- | :--- | :--- |
| **A：网页打开慢，但下载速度正常** | **高延迟 (Latency)** | 选用了跨大洋的远距离节点（如欧美），物理往返耗时长 | 切换到地理位置近的香港、日本或新加坡低延迟节点 |
| **B：网页秒开，但大文件下载极慢** | **低带宽 (Bandwidth)** | 节点机房上行带宽过小，或服务商针对单连接进行了限速 | 切换到标有“专线/大带宽”的高品质节点 |
| **C：看 YouTube/TikTok 频繁缓冲** | **高丢包率 (Packet Loss)** | 普通公网中转遭遇骨干网丢包，TCP 传输窗口剧烈暴跌 | 切换至丢包率低于 0.1% 的 IPLC / IEPL 专线节点 |
| **D：外服手游联机延迟高或瞬移** | **抖动 (Jitter) 与 UDP 丢包** | 游戏数据包被普通代理排队，或基站 UDP 阻断 | 选用标有“游戏专线”节点，确保开启 UDP 转发支持 |
| **E：白天飞快，一到晚上 8 点后卡死**| **晚高峰拥塞 (Peak Hour)** | 国际公网海缆出口塞车，机场用户并发激增超售 | 手动切换至新加坡或美国冷门大带宽节点避开高峰 |
| **F：国内微信淘宝卡顿，外网正常** | **路由策略误配** | 全局路由错误选成了【代理 (Proxy)】导致国内流量绕美 | 将首页全局路由切实切换回【配置 (Config)】智能分流 |

## 二、四大网络指标深度辨析：为什么 25ms 香港节点看 4K 会卡？

初学者最容易陷入的误区就是盲目追求节点列表里的“最低毫秒数”：

```text
 ┌─────────────────────────────────────────────────────────────────────────────────────────────┐
 │                               【四大性能指标的物理真相深度解密】                            │
 ├──────────────────┬──────────────────────────────┬───────────────────────────────────────────┤
 │ 核心性能指标     │ 真实物理含义                 │ 对日常 iPhone 上网体验的决定性影响        │
 ├──────────────────┼──────────────────────────────┼───────────────────────────────────────────┤
 │ **1. Latency**   │ 手机与服务器之间握手往返时间 │ 决定网页点开的瞬时响应快慢（毫秒越小反应越灵敏） │
 │ **2. Bandwidth** │ 单位时间内能传输的最大数据量 │ 决定下载大文件与看 4K 高码率视频的上限（MB/s）    │
 │ **3. Packet Loss**| 数据包在半路丢失的百分比    │ 丢包超 5% 就会导致视频卡死、网页假死、游戏频繁瞬移│
 │ **4. Jitter**    │ 延迟波动的剧烈程度（不稳定度）| 延迟在 30ms 与 300ms 间剧烈跳跃，严重破坏语音联机 │
 └──────────────────┴──────────────────────────────┴───────────────────────────────────────────┘
```

### 为什么 25ms 香港节点看视频卡，130ms 美国节点看 4K 秒开？
- **25ms 香港节点**：距离近、握手延迟极低，但机房若只配备了 20Mbps 廉价共享带宽，晚高峰百人并发瞬间挤爆，丢包率飙升至 20%，视频流因反复重传而卡死转圈；
- **130ms 美国节点**：虽然跨越太平洋有 130ms 延迟，但其机房配备了 10Gbps 独立大带宽，丢包率常年为 0，视频缓冲条一瞬间拉满几十秒。
- **选点黄金法则**：日常办公查资料选 **低延迟香港/日本节点**；刷 YouTube 4K、看 Netflix 选 **大带宽专线或欧美节点**。

## 三、重大认知纠偏：节点“倍率”是速度的意思吗？

在小火箭订阅中经常看到 `香港 01 [2.0x]` 或 `美国 02 [0.2x]`：

```text
 ⚠️ 【新手最普遍的认知误解】：
 “2.0x 节点是不是代表速度比普通节点快 2 倍？0.2x 节点是不是速度慢 5 倍？”
 
 真实技术内幕：
 - 【倍率完全属于计费倍数，绝不代表物理网速！】
 - 2.0x 代表你实际消耗 1GB 流量，机场后台扣除 2GB 配额（通常因为该节点租用了极其昂贵的高品质独享 IPLC 专线）；
 - 0.2x 代表你消耗 1GB 流量，后台仅扣除 200MB（通常为廉价公网中转节点）；
 - 很多 0.2x 节点的闲置带宽非常大，非晚高峰时看 4K 视频一样秒开，是用来跑大流量下载的高性价比首选！
```

## 五、iOS 本地特性排查：Wi-Fi 干扰与低电量模式陷阱

除了网络线路，iPhone 本身的硬件与系统状态同样会卡住网速：

```text
 1. 【本地 2.4GHz Wi-Fi 频段干扰】：
    - 若手机连接的是老旧的 2.4GHz Wi-Fi，受到蓝牙和邻居路由器的严重同频干扰，真实无线吞吐量可能暴跌至 5Mbps 以下；
    - 应对：在路由器后台强制连接 5GHz 频段，或关掉 Wi-Fi 改用手机 5G 蜂窝网络对比。

 2. 【iPhone 低电量模式对代理扩展的压制】：
    - 当 iPhone 电量低于 20% 开启【低电量模式】时，iOS 会对后台 Network Extension 进程进行极其严苛的 CPU 降频与休眠限制；
    - 严重时会导致小火箭解密数据包出现延迟断流；给手机充电或关闭低电量模式即可恢复。
```

## 六、目标网站 CDN 调度异常与单站卡顿排查

如果仅有某一个特定海外网站（如 GitHub 或某个小众论坛）极其缓慢，其他网站飞快：

```text
 1. 【出口 IP 触发目标平台 WAF 限速】：
    - 大型平台会根据访问者的出口 IP 进行信誉评分；若当前节点 IP 被判定为机房代理，可能会被目标服务器施加单连接速率限制；
 2. 【分流规则误判导致国内直连】：
    - 检查该域名是否未被分流规则收录，导致手机直接通过本地网络“裸连”该海外网站；
 3. 【解决办法】：
    - 打开小火箭【设置】──►【请求日志】确认该网站走的是 Proxy 还是 Direct；
    - 在小火箭中切换到另一个不同国家的节点，更换全新出口 IP 即可秒级解决。
```

## 九、常见问题解答 (FAQ)

### Q1：为什么节点旁边显示的延迟只有 30ms，但实际下载速度却只有几百 KB/s？
**答**：因为 30ms 仅代表你的手机与该服务器之间的握手往返延迟极低；而下载速度取决于该节点配备的物理带宽上限以及当前有多少用户在并发抢占通道。

### Q2：看 YouTube 4K 视频老是卡顿缓冲，应该重点排查什么？
**答**：重点排查**丢包率 (Packet Loss) 与晚高峰拥堵**。公网跨境传输一旦出现 5% 以上的丢包，视频流传输协议就会启动退避重传导致断流；切换到丢包率极低的专线节点（如 IPLC）即可完美解决。

### Q3：为什么白天看视频非常流畅，一到晚上 8 点至 11 点就卡得无法使用？
**答**：这是极其典型的“国际出口晚高峰骨干网拥塞”：全国海量用户集中访问外网，导致公网海缆发生物理级拥堵；建议在晚高峰避开拥挤的热门香港一号节点，改用抗拥塞的专线节点或相对冷门的新加坡节点。

### Q4：节点倍率（如 2.0x 或 0.2x）代表什么？倍率越高速度越快吗？
**答**：**不代表网速！** 倍率纯粹是机场的计费倍数（2.0x 代表用 1G 扣除 2G 流量）。虽然高倍率节点通常成本较高、人数较少，但不代表物理速度绝对翻倍；很多 0.2x 节点在非高峰期同样能跑满几百兆。

### Q5：手机连家里 Wi-Fi 测速很慢，但切成 5G 蜂窝网络却非常快是什么原因？
**答**：这证明机场节点完全正常，瓶颈 100% 在家里的 Wi-Fi 信号上！通常是因为手机连入了 2.4GHz 干扰严重的频段、路由器散热不良，或宽带运营商对该网络进行了限速；切换到 5GHz Wi-Fi 即可恢复。

### Q6：开启全局模式 (Proxy) 会让小火箭翻墙速度变快吗？
**答**：**绝对不会！** 全局模式只是强制让国内所有流量也走代理，不会为节点增加任何物理带宽；反而会导致微信、淘宝等国内应用全部强行绕道海外，造成严重的国内网络卡顿。

### Q7：外服手游联机时延迟很低，但角色频繁“瞬移/丢操作”是怎么回事？
**答**：属于典型的**网络丢包与抖动 (Jitter)**。联机对局极其依赖平稳无损的 UDP 数据传输，中间链路一旦发生丢包就会导致操作数据丢失；在小火箭中选用标有“游戏专线/低丢包”的节点即可改善。

### Q8：怎么在 Shadowrocket 中确认某个慢网页到底走了什么节点和规则？
**答**：打开小火箭底部【设置】──► 开启【请求日志 (Requests)】。打开该卡顿网页后返回小火箭请求列表，点击对应请求即可直观查阅当前实际分流指派的策略与具体走出的节点。
