> **Clash Verge Rev** 是一个支持 Windows、macOS 和 Linux 的新一代跨平台开源图形化代理客户端，深度集成了持续活跃维护的 **Mihomo（原 Clash.Meta）内核**。它具备优雅的全中文交互界面，并全面兼容 Hysteria 2、TUIC v5、VLESS 等下一代前沿抗封锁传输协议。对于新手而言，完成基础使用通常只需下载正确系统架构版本、导入有效订阅配置、选择节点并开启 System Proxy；若有游戏加速或终端代理需求，亦可一键启用 TUN 虚拟网卡。本文系统梳理了从安装包选型、各平台安装、订阅管理、分流模式切换，到内核管理与高频故障排查的完整全生命周期使用指南。

## ⚡ 30 秒快速开始 (Quick Start)

**如果你已经拥有有效的机场订阅链接，开启科学上网只需以下简明八步：**

```text
1. 从 Clash Verge Rev 官方项目发布渠道下载与你的系统和 CPU 架构对应的安装包。
2. 完成安装并首次启动 Clash Verge Rev 客户端。
3. 点击左侧导航栏打开「订阅 (Profiles)」页面。
4. 在顶部输入框粘贴有效的订阅链接（URL）并点击「导入 (Import)」。
5. 单击高亮激活刚下载的配置，进入「代理 (Proxies)」页面选择节点。
6. 代理模式优先保持在「Rule (规则模式)」，实现国内外流量智能分流。
7. 进入「设置 (Settings)」面板，打开「系统代理 (System Proxy)」开关。
8. 若部分开发终端或游戏不走系统代理，再考虑安装服务并开启「TUN 模式」。
```

> ⚠️ **新手避坑关键**：首次使用时请勿在后台同时运行多个代理客户端（如 v2rayN、Sing-box 或旧版 CFW），避免产生本地端口（7890/7897）冲突或系统代理注册表覆写。

## 一、Clash Verge Rev 是什么？

```text
┌───────────────────────────────────────────────────────────┐
│              Clash Verge Rev 图形化用户界面 (GUI)            │
│  (提供订阅管理、节点可视化切换、分流规则配置、TUN 开关与系统代理控制) │
└─────────────────────────────┬─────────────────────────────┘
                              │ API 控制与配置下发
┌─────────────────────────────▼─────────────────────────────┐
│                 Mihomo (Clash.Meta) 兼容内核                │
│  (负责底层数据包路由、DNS 解析、TLS 握手、协议解密与流量转发) │
└───────────────────────────────────────────────────────────┘
```

**Clash Verge Rev** 本质上是一个现代化的**跨平台图形用户界面管理器（GUI Client）**。

其自身并不直接执行底层网络数据包的路由运算，而是通过调用内置的 **Mihomo（原 Clash.Meta）内核** 来执行具体的加密解密、规则匹配、DNS 解析与流量出站。通过优雅的界面设计，Clash Verge Rev 将复杂的 YAML 配置文件转化为直观的可视化开关，让普通用户无需敲击任何终端命令即可轻松驾驭强大的规则分流体系。

## 三、Clash Verge Rev 和 Mihomo 是什么关系？

为了更形象地理解它们之间的协作关系：
- **Clash Verge Rev $\approx$ 汽车的仪表盘与方向盘（控制台）**：负责向用户展示当前车速（实时流量）、导航路线（分流规则）、挡位切换（节点策略）及空调开关（系统代理/TUN）。
- **Mihomo Core $\approx$ 汽车的发动机与底盘（动力引擎）**：负责在发动机舱内部高速运转，执行真正的数据包加密传输与路由处理。

两者分工明确，相辅相成。

## 四、下载前应该确认什么？

在下载安装包前，请在本地电脑上完成以下三项基础确认：

1. **核对操作系统与处理器架构**：
   - **Windows 用户**：打开「设置」 $\rightarrow$ 「系统」 $\rightarrow$ 「关于」，查看“系统类型”是基于 x64 还是 ARM64 处理器。
   - **Mac 用户**：点击左上角苹果图标 $\rightarrow$ 「关于本机」，确认是 Apple M 系列芯片（M1/M2/M3/M4）还是 Intel 处理器。
2. **警惕第三方下载站与篡改包**：
   - 切勿从个人网盘、非官方博客或未经审计的下载站获取所谓的“破解汉化版”，此类安装包极易被夹带后门程序或挖矿木马。
3. **确认本地安装目录无特殊符号**：
   - 安装路径建议保持英文目录，避免包含特殊字符导致内核无法正常读写日志缓存。

## 十三、导入订阅后没有节点怎么办？

如果提示导入成功，但点击左侧“代理”页面列表空空如也，请按以下表格排查：

| 异常表现 | 优先排查方向 | 推荐应对措施 |
| :--- | :--- | :--- |
| **订阅导入直接提示 Network Error** | 订阅链接被本地网络拦截或机场分发服务器故障 | 使用手机热点重试，或联系机场获取备用订阅域名 |
| **导入成功但显示 0 个节点** | 账户流量耗尽、套餐已到期，或返回了空配置 | 登录机场官网确认账户余额与套餐状态 |
| **订阅卡片存在但代理页没内容** | 忘记单击激活该配置卡片 | 在“订阅”页面中左键点击配置卡片使其高亮激活 |
| **节点存在但全部显示红色 Timeout** | 本机系统时间偏差、内核假死或网络被阻断 | 立即参考 👉 **[Clash 节点全红排查教程](/issues/clash-nodes-timeout/)** |

## 十五、节点延迟怎么看？（正确理解 URL Test）

- **执行测速**：在“代理”页面右上角点击 **⚡ 闪电测速图标**，客户端会并发向测试服务器发送握手检测。
- **延迟数值客观认知**：
  - **绿色（如 35ms ~ 85ms）**：近邻低延迟专线，网页响应极快。
  - **黄色（如 130ms ~ 220ms）**：美欧长距离节点，适合跨洋业务与原生流媒体。
  - **红色 Timeout**：连接超时不可达。
- **专业提醒**：很多用户口语化称其为“Ping”，但 Clash 绝大多数使用的是应用层 **URL Test**。延迟低（毫秒小）仅代表握手响应快，并不等同于下载大文件的最高速率（MB/s）。

## 十六、Rule、Global、Direct 代理模式有什么区别？ (表 3)

代理模式决定了数据包的流向判断逻辑：

| 模式名称 | 流量路由机制 | 适用场景 | 优缺点分析 |
| :--- | :--- | :--- | :--- |
| **Rule (规则分流 - 强烈推荐)** | 根据规则判定：国内直连，国外受阻流量走代理 | **99% 日常使用场景** | 节省节点流量，国内 App/微信完全不受影响，无感加速 |
| **Global (全局代理)** | 所有网络请求强制通过选定节点出站 | 临时排查分流规则失灵、访问冷门海外网站 | 国内网站变慢且浪费代理流量，**若节点超时整机断网** |
| **Direct (全局直连)** | 所有请求直接由本地网卡发出，完全绕过代理 | 临时停用代理功能、测试本地宽带原生表现 | **处于该模式时无法打开任何被阻断的海外网站** |

## 十七、System Proxy（系统代理）是什么？

**System Proxy** 是操作系统层面的标准代理通道：
- 开启后，Clash 会在 Windows/macOS 系统网络中注册本地代理端口（默认为 `127.0.0.1:7897`）。
- 任何遵循系统代理规范的软件（Chrome、Edge、Safari、Firefox 及主流桌面应用）都会自动将流量移交给 Clash Verge 处理。

进入「设置」面板 ──► 找到「系统代理 (System Proxy)」 ──► 点击滑块开启 (变为激活色) ──► 打开浏览器立即生效

## 十九、开启系统代理后无法上网怎么办？

如果一打开系统代理连国内网页都打不开：
1. **立即关闭系统代理**，确认国内网络是否立刻恢复。
2. 打开“代理”页面，确认当前选择的节点**不是红色 Timeout 节点**。
3. 确认代理模式处于 **「Rule」** 模式而非选了失效节点的「Global」。
4. 详细排查步骤请参考深度诊断专文：👉 **[Clash 开启系统代理后断网全排查指南](/issues/clash-nodes-timeout/)**。

## 二十、TUN 虚拟网卡模式是什么？

部分应用程序（如网络游戏客户端、CMD/PowerShell 命令行终端、Git 同步、WSL2 子系统等）**并不遵守操作系统的 System Proxy 代理设置**，导致流量漏出直连。

**TUN 模式（Virtual Network Interface）** 通过在操作系统内核层创建一张虚拟网卡，直接在网卡驱动层拦截整机所有 TCP/UDP 数据包，实现 100% 真正的全流量无死角接管。

---

## 二十一、System Proxy vs TUN 深度对比 (表 4)

| 对比维度 | System Proxy (系统代理) | TUN 虚拟网卡模式 |
| :--- | :--- | :--- |
| **工作层级** | 操作系统应用层（HTTP/SOCKS5） | 驱动内核层（虚拟网卡 L3 流量拦截） |
| **接管范围** | 浏览器及常规遵守系统代理的桌面应用 | **整机所有流量**（含终端、游戏、UWP、虚拟机） |
| **系统权限要求** | 普通用户权限即可正常运行 | **必须具备 Windows / Mac 系统管理员权限** |
| **配置复杂度** | 极简，一键点击开关即可 | 首次使用需安装虚拟网卡服务模式驱动 |
| **网络游戏加速** | 不支持（UDP 流量通常不走系统代理） | **完美支持外服游戏联机与 UDP 加速** |
| **新手选型建议** | **新手上网首选（足够满足日常需求）** | **有终端命令行、开发或游戏需求时再开启** |

## 二十二、Clash Verge Rev 怎么开启 TUN 模式？

1. **安装服务模式（Service Mode）**：
   - 进入 **「设置」** $\rightarrow$ 找到 **「服务模式」** $\rightarrow$ 点击右侧的 **「安装」**。
   - 弹出 UAC 提权提示点击“是”，安装成功后旁边会出现绿色小圆点。
2. **以管理员身份运行客户端**：
   - 彻底退出软件，右键桌面 Clash Verge 图标选择 **「以管理员身份运行」**。
3. **开启 TUN 开关**：
   - 进入设置，找到 **「TUN 模式 (TUN Mode)」** 开关并点击开启。
   - 此时在 Windows 网络适配器中会生成名为 `Mihomo` 的虚拟网卡，整机流量接管成功。

## 二十三、TUN 开启后无法上网怎么办？

- **优先排查**：确认是否同时开了其他带有虚拟网卡的软件（如 VMware 虚拟机、旧版 TAP 驱动或其他加速器）。
- **重置驱动**：在设置中先关闭 TUN 模式，点击卸载服务模式，重启电脑后重新安装服务并以管理员权限启动。

## 二十四、Mihomo（原 Clash.Meta）内核深度解析

**Mihomo** 是目前开源社区中最先进、更新最频繁的 Clash 兼容内核分支：
- **全协议覆盖**：完美支持 VLESS、VMess、Trojan、Shadowsocks、Hysteria 2、TUIC v5、WireGuard 等。
- **智能分流引擎**：支持基于域名规则集（Rule-Set）、GeoIP、GeoSite 数据库的高性能毫秒级匹配。
- **自适应路由**：具备强大的 DNS 缓存与 Fake-IP 机制，彻底规避本地 DNS 污染。

## 二十八、IPv6 设置要不要开启？

- **建议策略**：**默认保持关闭（除非明确需要 IPv6 场景）**。
- **原因**：部分国内宽带运营商的 IPv6 出境路由较差且容易断流，开启 IPv6 容易导致某些流媒体或 ChatGPT 触发风控拦截。

## 二十九、DNS 设置需要手动修改吗？

- **建议策略**：**保持客户端默认配置即可**。
- Clash Verge Rev 内置了经过深度优化的 **Fake-IP 模式**，能够有效阻断本地 DNS 污染并将解析请求安全交由远端节点处理。若需针对 AI 工具调优，可参考：👉 **[ChatGPT 访问异常排障指南](/issues/chatgpt-access-denied/)**。

## 三十五、新手常见错误避坑汇总

在日常使用中，避免以下常见误区可减少 90% 的使用烦恼：
1. **架构选错**：Windows x64 电脑误下载 ARM64 安装包导致无法运行。
2. **多客户端冲突**：同时开启 Clash for Windows 与 Clash Verge Rev 导致端口冲突。
3. **忘记选节点**：导入订阅后未在“代理”页面选择具体节点。
4. **误开 Direct 模式**：将模式误设为 Direct 导致海外网站完全无法打开。
5. **盲目开启 TUN**：在未安装服务模式或未提升管理员权限时强开 TUN 导致断网。
6. **把 URL Test 当成实际网速**：认为 30ms 延迟一定比 80ms 延迟下载文件更快。

## ❓ 常见问题解答 (FAQ)

### Q1: Clash Verge Rev 是什么？
> **答**：Clash Verge Rev 是一款基于 Tauri 框架打造的现代跨平台代理客户端，用于导入机场订阅、管理节点、执行智能分流及控制系统代理/TUN 模式。

### Q2: Clash Verge Rev 去哪里下载？
> **答**：请认准官方 GitHub 仓库：`clash-verge-rev/clash-verge-rev/releases` 获取最新安装包，避免下载第三方篡改版本。

### Q3: Clash Verge Rev 安全吗？
> **答**：软件代码在 GitHub 完全开源，不包含任何恶意后门代码。只要从官方 Release 仓库下载并导入可信的订阅，安全性极高。

### Q4: Windows 应该下载哪个安装包？
> **答**：绝大多数 Intel/AMD 处理器的 64 位电脑下载 `Clash.Verge_x64-setup.exe` 即可；若为高通骁龙等 ARM 处理器电脑，请下载 `arm64` 版本。

### Q5: Mac M1/M2/M3/M4 应该选哪个版本？
> **答**：所有 Apple Silicon 系列芯片的 Mac 电脑请下载 `aarch64.dmg` 版本；早期的 Intel 处理器 Mac 请下载 `x64.dmg` 版本。

### Q6: Clash Verge Rev 怎么设置中文？
> **答**：进入设置（Settings）面板，在 Verge Setting 区域找到 Language 选项，切换为“简体中文”即可实时生效。

### Q7: 怎么导入机场订阅？
> **答**：在“订阅”页面顶部输入框粘贴订阅 URL 并点击导入，下载成功后鼠标左键单击该卡片使其高亮激活即可。

### Q8: 为什么导入订阅后没有节点？
> **答**：请确认在“订阅”列表中左键单击了该卡片以激活它；若仍无节点，请右键查看配置内容是否完整，或检查订阅链接是否已过期。

### Q9: 怎么选择节点？
> **答**：进入“代理 (Proxies)”页面，展开对应的策略组（如 PROXY），鼠标左键点击你需要的国家或地区节点即可切换。

### Q10: Rule、Global 和 Direct 该选哪一个？
> **答**：绝大多数日常场景请坚决保持在 **Rule (规则模式)**。只有在调试特定网站或分流规则失效时，才临时使用 Global 模式。

### Q11: System Proxy 是什么？
> **答**：System Proxy 是操作系统级标准代理开关，开启后浏览器等常规应用会自动将流量交给客户端处理。

### Q12: TUN 模式是什么？
> **答**：TUN 模式通过在系统内核层创建虚拟网卡，接管整机所有网络流量，适合外服游戏联机与不支持系统代理的终端命令行。

### Q13: System Proxy 和 TUN 模式有什么区别？
> **答**：System Proxy 主要接管浏览器等遵循系统代理的软件；TUN 模式通过虚拟网卡拦截整机底层所有网络流量，适合游戏联机与终端开发。

### Q14: 为什么开启系统代理后无法上网？
> **答**：说明端口冲突或选中的节点已离线。请在“代理”中切换可用节点，或进入设置修改 Mixed-Port 端口（如改为 17897）。

### Q15: 开启 TUN 模式后断网怎么办？
> **答**：请确认以“管理员身份”运行软件，并检查是否已在设置中成功安装“服务模式 (Service Mode)”虚拟网卡驱动。

### Q16: 节点测速全部显示 Timeout 怎么解决？
> **答**：90% 的原因是本地电脑系统时间与标准北京时间存在偏差。请在系统设置中点击“立即同步时间”，随后重启软件。

### Q17: Clash Verge Rev 和 Clash for Windows 哪个好？
> **答**：Clash Verge Rev 完胜。CFW 早已停更且不支持现代协议，而 Clash Verge Rev 持续维护、搭载先进的 Mihomo 内核且内存占用更低。

### Q18: Mihomo 内核是什么？
> **答**：Mihomo（原 Clash.Meta）是负责底层数据加密、路由转发与 DNS 规则匹配的核心引擎，Clash Verge Rev 是其外层的可视化操作界面。

### Q19: 怎么设置订阅自动更新？
> **答**：右键订阅卡片选择“编辑”，将“更新间隔”设置为 1440 分钟（即 24 小时），客户端就会在后台定时自动拉取最新节点。

### Q20: 如何查看运行日志？
> **答**：点击左侧导航栏的“日志 (Logs)”页面，即可实时监控内核运行状态并定位端口冲突或超时错误。
