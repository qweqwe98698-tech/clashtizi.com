## 八、常见高频问题解答 (FAQ)

### Q1：免费节点和付费节点在技术上最核心的差异是什么？
**答**：四大核心技术差异：①**出口 IP 属性**（免费为万人共用机房广播 IP，付费为纯净原生双 ISP 住宅 IP）；②**UDP 支持**（免费 99% 关闭 UDP 无法游戏，付费支持 Full-cone NAT）；③**物理通道**（免费走公网海缆丢包 50%，付费走 IPLC 点对点专线 0 丢包）；④**网络抖动**（免费抖动 > 150ms 频繁断流，付费标准差 `< 1.5ms`）。

### Q2：为什么打外服游戏（如 Steam/Apex/暴雪）绝对不能用免费节点？
**答**：因为免费节点为了防攻击，在防火墙中强制关闭了 UDP 转发；而所有联机网游的实时位置数据与语音均通过 UDP 传输。在免费节点下游戏会直接报错“无法连接服务器”或出现 100% 丢包卡死。

### Q3：为什么用免费节点打开 ChatGPT 提示 1020 报错？
**答**：免费节点使用的是公开发布在全网的廉价广播机房 IP，成千上万人在同一 IP 下并发请求，早已被 OpenAI 判定为恶意爬虫黑名单；付费机场配备 **原生双 ISP 住宅 IP**，欺诈分 `< 5`，秒进 ChatGPT-4o。

### Q4：低 Ping 为什么看视频依然卡顿转圈？
**答**：Ping 仅仅代表单个 ICMP 小数据包的往返时间；而观看 4K 视频依赖于 **单 TCP 连接的持续高吞吐带宽与 0 丢包率**。免费节点在晚高峰公网丢包率超 50%，TCP 窗口不断减半降速，导致低 Ping 依然卡死。

### Q5：主流客户端（Clash Verge、小火箭、v2rayN）如何设置付费专线节点优先？
**答**：在客户端【策略组 (Proxy Groups)】设置中，将【节点选择】默认指定为你购买的【IPLC 香港/日本专线】，将免费节点作为列表底部的备用兜底，开启【Rule 规则模式】即可全自动智能分流。

### Q6：什么是 Full-cone NAT？它对游戏有什么影响？
**答**：Full-cone NAT（全锥型 NAT）允许内部端口与外部所有服务器自由建立双向 UDP 通信；能将游戏 NAT 类型提升为 Type A / Open，杜绝联机房间加入失败与语音断连。

### Q7：什么是原生住宅 IP？怎么检测？
**答**：原生住宅 IP 是海外真实家庭宽带运营商分配的纯净民用 IP。在浏览器访问 `ipinfo.io` 或 `scamalytics.com` 查询：若 `Type` 显示为 `isp` 且 `Fraud Score < 10`，即为最高品质的原生住宅 IP。

### Q8：遇到免费节点突然大面积全红超时怎么办？
