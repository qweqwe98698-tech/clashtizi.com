> **【💡 30 秒极速直接答案：v2rayN 连上但没网核心定性与四大排障原则】**
> - **第一核心定性**：**“右下角托盘图标变红、节点测速有绿色毫秒数，绝对不等于浏览器已经能上网！”** 托盘变红仅代表注册表写入了代理地址，节点有延迟仅代表握手成功；如果浏览器依然打不开网页，属于**本地流量入口未打通、浏览器扩展冲突、路由规则误判或 DNS 死锁**；
> - **六类典型“连上没网”极速分诊与应对**：
>   1. **浏览器报错“代理服务器连接失败 / ERR_PROXY_CONNECTION_FAILED”** ──► 本地 10809 端口被冲突占用或被杀毒软件切断 ──► 重启客户端或改本地端口；
>   2. **国外网站秒开，但国内微信、淘宝全线转圈卡死** ──► 底部路由误切成了【全局 (global)】 ──► 切回【绕过大陆 (bypass-mainland)】；
>   3. **无论国内还是国外网站全打不开** ──► 底部路由误切成了【直连 (direct)】，或选中的节点出口断网 ──► 换节点并改路由；
>   4. **Chrome 浏览器正常翻墙，但 Telegram、Discord、Git 命令行不能用** ──► 这些独立应用无视 Windows 系统代理 ──► 开启【TUN 模式】或软件内手动配 SOCKS 10808；
>   5. **直接输入海外纯 IP 能开，输入网址显示无法访问** ──► 本地 DNS 解析死锁 ──► 检查 DNS 设置并恢复默认；
>   6. **Chrome 打不开但 Edge 却能开** ──► Chrome 安装了 SwitchyOmega 等代理插件截胡了流量 ──► 将插件切换为“系统代理”模式。

## 一、六大典型“连上没网”现象分类与第一优先级排查对照表

在排查前，请对照下表确认你的电脑到底卡在第几层：

| 故障现象分类 | 核心阻断层级 | 最核心真实诱发诱因 | 第一步标准应对动作 |
| :--- | :--- | :--- | :--- |
| **A：浏览器提示“代理服务器拒绝连接”** | 本地端口监听层 | 10809 端口未监听，或杀毒软件切断了本地回环 | 重启 v2rayN，或检查任务管理器内核是否存活 |
| **B：外网秒开，但国内微信淘宝全卡死** | 路由分流模式层 | 底部路由选成了【全局 (global)】，国内流量绕道海外 | 将底部路由切实切换回【绕过大陆 (bypass-mainland)】 |
| **C：国内外所有网页全转圈打不开** | 节点出站/路由层 | 选中的节点出口断网，或路由误切成了【直连 (direct)】 | 切换同分组下的其他绿色节点，确认路由为绕过大陆 |
| **D：浏览器正常，但电报/Git终端不通** | 软件代理机制层 | 这些独立软件默认不读取 Windows 注册表系统代理 | 开启小火箭【TUN 模式】，或在软件内填 127.0.0.1:10808 |
| **E：Chrome 报错，但 Edge 浏览器正常** | 浏览器插件冲突层 | Chrome 中安装的 SwitchyOmega 插件覆盖了系统代理 | 打开 Chrome 插件，将模式勾选为【使用系统代理】 |
| **F：勾选开启 TUN 模式后电脑直接断网** | 虚拟网卡驱动层 | 未以管理员身份运行，或 Wintun 驱动与杀软冲突 | 右键 v2rayN.exe 选择“以管理员身份运行” |

## 二、黄金第一步：检查 Windows 注册表系统代理是否真正写入

v2rayN 托盘图标变红，理论上代表向 Windows 写入了系统代理，但很多电脑因为杀毒软件或组策略拦截导致“写入失败”：

```text
 1. 【手动核验 Windows 代理写入状态】：
    - 按下快捷键 `Win + I` 打开 Windows【设置】；
    - 点击【网络和 Internet】──► 选择【代理】；
    - 检查“手动设置代理”区域：
      * 【使用代理服务器】：是否处于【开】状态？
      * 【代理 IP 地址】：是否严格为 `127.0.0.1`？
      * 【端口号】：是否严格为 `10809`？

 2. 【若开关处于“关”或灰色无法修改】：
    - 证明 360、火绒或公司域控组策略锁死了注册表代理写入；
    - 解决办法：在杀毒软件中将 v2rayN 设为信任白名单，允许其修改系统网络配置。
```

## 五、独立桌面软件（Telegram / Discord / Git）不走代理排查

为什么打开网页飞快，但电脑桌面上的 **Telegram 显示无限 Connecting**、**Git 命令行报错**？

```text
 1. 【传统系统代理的局限性】：
    - Windows 的【系统代理】本质上是应用层 HTTP 代理（WinINet API）；
    - 只有 Chrome、Edge 等遵循该标准的现代浏览器会自动走代理；
    - Telegram、Discord、游戏客户端、CMD/PowerShell 默认完全无视 Windows 系统代理！

 2. 【两大彻底解决方案】：
    - 方案 A（最爽）：**勾选主界面下方的【启用 TUN 模式】**！通过虚拟网卡接管整机所有网络协议，任何软件无需任何设置即可自动翻墙；
    - 方案 B（单独设置）：打开 Telegram 设置 ──►【高级】──►【网络连接】──► 添加代理：
      * 协议选：`SOCKS5`；
      * 主机名填：`127.0.0.1`；
      * 端口填：`10808`（v2rayN 默认 SOCKS 本地端口）；保存后电报秒连！
```

## 六、TUN 模式开启后直接断网：管理员权限与驱动冲突解决

开启 TUN 模式虽然强大，但它涉及到 Windows 底层驱动：

```text
 1. 【为什么开启 TUN 后反而没网？】：
    - 原因 A：v2rayN 未以管理员身份启动，导致无权向系统安装 `wintun.dll` 虚拟网卡；
    - 原因 B：电脑上同时安装了其他虚拟网卡（如 TAP-Windows、旧版 Clash TUN），引发网关跃点数 (Metric) 冲突；
    - 原因 C：杀毒软件直接拦截了 Wintun 驱动的加载。

 2. 【标准排查与修复步骤】：
    - 退出 v2rayN；
    - 找到解压目录下的 `v2rayN.exe`，右键选择【以管理员身份运行】；
    - 打开主界面【设置】──►【TUN 模式设置】，确认核心选择为【Sing-box】或【Xray】；
    - 勾选【启用 TUN 模式】，观察托盘与网络连接中是否多出了一张虚拟适配器。
```

## 九、常见问题解答 (FAQ)

### Q1：为什么 v2rayN 托盘图标已经变红了，但浏览器还是打不开任何外网？
**答**：图标变红仅代表 v2rayN 在 Windows 注册表中配置了代理地址，不代表远程节点连接成功。常见原因包括：当前选中的节点服务器出口断网（按 `Ctrl+R` 测试真延迟确认）、本地 `10809` 端口冲突、或路由误设为了【直连】模式。

### Q2：浏览器提示“代理服务器拒绝连接 / ERR_PROXY_CONNECTION_FAILED”怎么办？
**答**：说明浏览器尝试连接 `127.0.0.1:10809`，但后台并没有核心程序在监听该端口！检查任务管理器中 `xray.exe` 是否被杀毒软件查杀闪退，或在 v2rayN 参数设置中更换一个未被占用的端口号。

### Q3：为什么开启代理之后，国内的微信、百度、网银极其卡顿？
**答**：**99% 是因为底部路由选成了【全局 (global)】模式！** 这导致国内所有请求被迫强行绕道欧美服务器；在 v2rayN 底部将路由切换回 **【绕过大陆 (bypass-mainland)】** 智能分流模式即可秒级恢复。

### Q4：为什么 Edge 浏览器能翻墙，但 Chrome 浏览器死活打不开网页？
**答**：这是极为典型的 **Chrome 浏览器插件截胡**！检查 Chrome 右上角是否安装了 SwitchyOmega 或其他代理插件。一旦安装了这类扩展，Windows 全局代理会被彻底忽略；在插件菜单中将模式切为【系统代理】即可。

### Q5：为什么网页能正常看 YouTube，但桌面版 Telegram 却一直转圈连接不上？
**答**：因为普通【系统代理】只接管标准网页流量，Telegram 默认不走 Windows 系统代理。解决办法：勾选客户端下方的【启用 TUN 模式】接管整机流量；或在 Telegram 高级连接设置中手动配置 SOCKS5 代理为 `127.0.0.1:10808`。

### Q6：底部的路由模式中，「绕过大陆」和「直连」有什么本质区别？
**答**：【绕过大陆】是智能分流：国内直连、国外走代理；【直连 (direct)】是全量不走代理，相当于关闭了梯子功能。日常上网必须选择【绕过大陆】。

### Q7：勾选开启「TUN 模式」之后，整台电脑反而彻底断网了怎么解决？
**答**：TUN 模式需要向系统加载驱动级虚拟网卡。必须在解压目录下右键 `v2rayN.exe` 选择【以管理员身份运行】；同时检查设备管理器中是否存在其他冲突的虚拟网卡，或暂时关闭杀毒软件的驱动拦截防护。

### Q8：遇到连上但打不开网页，最忌讳的操作是什么？
**答**：最忌讳“病急乱投医盲目重装系统或重置路由器”。按照“Ctrl+R 测真延迟 ──► 检查底部路由 ──► 检查浏览器插件 ──► 开启管理员 TUN”四步法，任何连上没网的故障都能在 3 分钟内彻底解决。
