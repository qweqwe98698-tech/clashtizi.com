> **【💡 黄金排查法则：昨天能用、今天不能用，先找“今天什么变了”！】**
> 
> 面对突发断网，90% 的新手会陷入“病急乱投医”的误区：反复清空订阅、盲目重装客户端甚至重置电脑网络——**这完全是在破坏排障线索！**
> - **突发失效必有变量发生变动**：排障的第一核心不是重新配置，而是**回忆与对比昨天到今天究竟发生了什么变化**；
> - **常见 4 大突发突变点**：① 机场套餐刚刚到期欠费；② 操作系统（Windows/iOS）夜间自动更新破坏了驱动；③ 客户端自动更新升级了内核；④ 机场分发了新订阅或正在例行机房维护。

## 一、“昨天 vs 今天”核心变量排查清单（比重装快 10 倍的方法）

在动手改任何设置前，请快速对照以下表格自查：

| 关键排查变量 | 昨天正常状态 | 今天发生的变化可能 | 快速自查与验证方法 |
| :--- | :--- | :--- | :--- |
| **机场套餐与账户** | 套餐有效、流量充裕 | **套餐在午夜刚好到期欠费** | 登录机场后台，查看订单与流量余量 |
| **操作系统更新** | 未更新 | **Windows/macOS 自动安装了补丁** | 检查系统更新历史，重新授权 TUN 虚拟网卡 |
| **客户端与 Core** | 旧版稳定运行 | **软件自动升级后内核未成功加载** | 在 [Clash Verge Rev](/clash-verge-rev/) 中点击【重启内核】 |
| **家庭网络环境** | 原 Wi-Fi 正常 | **光猫凌晨自动重拨，动态 IP 变化** | 手机连接 5G 热点做交叉对比测试 |
| **机场后端集群** | 线路稳定 | **服务商更换了节点域名或升级协议** | 在客户端右键点击配置卡片，选择【更新订阅】 |

## 二、第一层：账户、套餐与云端订阅状态排查

```text
 1. 登录机场官网后台 ──► 无法登录？ ──► [排查是否为服务商停服或更换新官网]
        ↓ 能够正常登录
 2. 检查【我的服务】 ──► 套餐是否过期欠费？ ──► [若已到期，续费后重新获取订阅]
        ↓ 套餐有效且流量充裕
 3. 点击【更新订阅】 ──► 是否报错 401/403/404？ ──► [若报错，去后台重新复制全新 URL 覆盖]
```

- **误区纠偏**：**“突然全失效”绝对不等于“机场跑路”**。绝大多数情况下只是套餐刚刚到期、机场例行迁移节点服务器、或本地 DNS 发生了短暂污染。

## 三、第二层：客户端、底层 Core 内核与系统更新排查

操作系统补丁或客户端升级是突发断网的高频元凶：

| 客户端与系统异常现象 | 底层根本原因 | 对应极速修复方案 |
| :--- | :--- | :--- |
| **Windows Update 之后全部失效** | 系统补丁重置了防火墙规则或禁用了 TUN 虚拟网卡驱动 | 以管理员身份运行客户端，重新安装 TUN 驱动 |
| **macOS 升级后提示代理异常** | 系统权限重置，客户端丢失了 NetworkExtension 授权 | 进入系统【隐私与安全性】，重新允许客户端网络扩展 |
| **客户端界面能点但测速毫无反应** | 底层代理核心（`clash-meta.exe`）崩溃或被 Defender 误杀 | 检查杀毒软件隔离区，客户端设置中点击【Restart Core】 |
| **切换为 Global 能用，Rule 彻底断网** | 远程分流规则库更新出现语法错误，将目标网址误判直连 | 手动切为【Global 全局模式】或更新订阅内的规则集 |

## 四、第三层：网络环境交叉验证（区分本地网络 vs 服务商故障）

这是 2 分钟内精准划分“责任归属”的黄金测试矩阵：

```text
                               【突发故障网络与设备交叉测试矩阵】
                                               │
 ┌─────────────────────────────────────────────┴─────────────────────────────────────────────┐
 │                                                                                           │
 📶 测试 A：电脑连接手机 5G 个人热点                                           📱 测试 B：使用另一台手机/平板连接同订阅
  - 若换热点后瞬间全绿恢复 ──► 证明是原 Wi-Fi 宽带问题                         - 若手机正常而电脑瘫痪 ──► 证明是电脑本地环境问题
  - 若所有网络所有设备均 100% 全红 ──► 证明是机场服务器集群故障                - 若所有客户端全部秒开 ──► 证明是原客户端配置损坏
```

### 交叉测试结果判定表：

| 测试场景组合 | 测试结果表现 | 结论与核心修复点 |
| :--- | :--- | :--- |
| **Wi-Fi 失败 / 手机热点正常** | 宽带无法连通，手机流量秒连 | **家庭光猫/路由器 DNS 被污染，重启光猫即可** |
| **手机正常 / 电脑全部失效** | 同一 Wi-Fi 下手机可用，电脑全挂 | **电脑系统代理残留、系统时钟偏差或防火墙拦截** |
| **Client A 挂 / Client B 正常** | Clash 无法使用，v2rayN 正常连通 | **Clash 配置文件损坏或 Core 核心版本过旧** |
| **所有设备所有网络均失效** | 换了 3 台设备和网络依然 100% 报错 | **机场云端发生整体故障或大面积机房线路维护** |

## 六、突发全失效排查九层诊断模型（9-Layer Diagnostic Model）

遇到突发性整体失效，严格按照以下 9 层顺序向下推进排查：

```text
 Layer 1: 账号资产层 ──► 登录官网核对套餐有效期与剩余流量
    ↓
 Layer 2: 订阅分发层 ──► 客户端执行一次【更新订阅】，确认 Token 未过期
    ↓
 Layer 3: 测速机制层 ──► 浏览器打开 Google 验证是否为 URL Test 误报
    ↓
 Layer 4: 节点连通层 ──► 观察是单节点超时还是全部全红
    ↓
 Layer 5: 客户端内核层 ──► 检查 Core 是否正常运行，重启代理内核
    ↓
 Layer 6: 系统代理与 TUN ──► 检查系统代理开关是否打开，排除端口残留
    ↓
 Layer 7: 分流规则层 ──► 切换为 Global 模式排除 Rule 规则误判
    ↓
 Layer 8: 网络出口层 ──► 切换手机 5G 热点排除家庭宽带与路由器故障
    ↓
 Layer 9: 目标服务层 ──► 区分通用网络故障与单个 AI / 流媒体平台风控
```

## 八、常见问题解答 (FAQ)

### Q1：梯子昨天还能正常使用，今天突然全部失效，最常见的三个原因是什么？
**答**：1. 机场套餐刚好到期欠费；2. 操作系统（Windows/iOS）自动更新破坏了代理网卡驱动或重置了防火墙；3. 本地家庭路由器光猫自动重拨后发生了 DNS 污染。

### Q2：突然不能用了，我应该立刻卸载重装客户端吗？
**答**：绝对不要第一步重装。重装会销毁现有配置、分流规则和排障日志。90% 的突发故障通过“检查套餐 ──► 更新订阅 ──► 切换手机热点”在 3 分钟内即可解决。

### Q3：订阅能够正常刷新，但所有节点测速全是红色 Timeout 怎么办？
**答**：这说明订阅层正常但节点连接受阻。优先切换为手机 5G 热点排除家庭宽带拦截，或在客户端设置中重启代理内核（Core），详见 [节点全红排查指南](/tizi/nodes-timeout/)。

### Q4：客户端显示已连接，但所有网页都打不开是怎么回事？
**答**：这是典型的“系统代理未开启”或“分流规则误判”。检查客户端是否开启了【系统代理 (System Proxy)】，并将分流模式切换为【Global 全局】测试。

### Q5：为什么手机连同一个订阅完全正常，电脑上却突然全挂了？
**答**：证明机场服务商完全正常。问题出在电脑本地：检查电脑系统时间是否偏差超过 1 分钟、杀毒软件是否拦截了代理内核、或开启了冲突的第三方加速器。

### Q6：遇到突发故障，怎么判断机场是不是跑路了？
**答**：切勿单凭一次断连就判定跑路。先登录机场官网后台查看能否访问，用手机 5G 流量连接测试，并关注机场官方群公告。只有多设备多网络持续数天无法访问时才考虑跑路可能。

### Q7：Windows 更新后梯子突然无法使用了怎么解决？
**答**：Windows 补丁经常重置虚拟网卡权限。以管理员身份重新打开客户端，在设置中重新安装 TUN 模式驱动，或将系统代理开关重新复位。

### Q8：为什么只有 ChatGPT 突然打不开，其他外网全部秒开？
**答**：这说明你的梯子没有任何故障。原因是该节点的机房 IP 触发了 OpenAI 的安全风控，换用日本/新加坡的原生节点即可恢复访问。

### Q9：把梯子软件关掉之后，电脑突然连百度都打不开了怎么办？
**答**：这是“系统代理残留”。按 `Win+I` 进入【网络和 Internet】──►【代理】，手动将“使用代理服务器”彻底关闭即可秒级恢复。

### Q10：为什么重新点击一次【更新订阅】后，所有节点瞬间恢复了？
**答**：因为机场后端对机房线路进行了例行维护或更换了出口 IP，旧的本地配置已失效，更新订阅会自动拉取最新的可用服务器列表。

### Q11：什么是“单变量测试原则”？为什么排查时必须一次只改一个设置？
**答**：如果同时换节点、换客户端、改 DNS 又重启电脑，即使网络恢复你也无法得知真正根因。固定其他条件，单次只测试一个变量才能精准定位问题。

### Q12：所有设备、所有网络测试全部节点都失效怎么办？
**答**：当手机 5G、家庭 Wi-Fi、所有客户端均无法使用时，大概率是机场服务器正在进行全网大规模机房割接维护，登录官网查看维护公告即可。
