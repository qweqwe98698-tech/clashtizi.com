> - **第一核心定性**：**“改 DNS 绝不是提升下载速度的万能神药！”** DNS 只负责将人类可读的网址（如 `google.com`）翻译成机器可寻址的 IP 地址。它只决定**点开网页前那 0.1 秒的建立耗时**，完全不增加节点的物理传输带宽；
> - **新手最佳免折腾黄金 DNS 组合**：
>   - **国内直连解析 (Direct Domain)**：使用国内顶级 Anycast 节点，如**阿里公共 DNS (`223.5.5.5`)** 或 **腾讯 DNSPod (`119.29.29.29`)**，确保国内应用秒开且 CDN 调度精准；
>   - **海外安全防污染解析 (Remote / Secure)**：配置加密 DNS（DoH / DoT），如 **Cloudflare (`https://1.1.1.1/dns-query`)** 或 **Google Public DNS (`https://dns.google/dns-query`)**，彻底免疫运营商 53 端口投毒；
> - **三类典型 DNS 故障极速诊断**：
>   1. **纯 IP 能打开网页，输入域名提示无法访问** ──► 100% 属于本地 DNS 解析死锁或配置了无效的私有 DNS；
>   2. **请求日志频繁跳出 `DNS Timeout`** ──► 当前配置的 DoH 服务器本身被宽带运营商屏蔽，切回系统默认或换用阿里 DoH；
>   3. **某些国外网站偶发打不开但换 5G 正常** ──► 遭遇家庭路由器 53 端口劫持投毒，在小火箭中开启 DoH 加密解析即可化解。

## 一、为什么小火箭里的 DNS 如此重要？（传统 UDP 53 劫持真相）

在移动互联网环境下，未加密的传统 DNS 是最脆弱的阿喀琉斯之踵：

| DNS 解析方式 | 底层传输协议与端口 | 传输安全性与抗干扰能力 | 在小火箭中的适用场景 |
| :--- | :--- | :--- | :--- |
| **传统 DNS** | **UDP / TCP 53 端口** | 🔴 **明文裸奔**，极易被宽带运营商监听、劫持或篡改投毒 | 仅适合用于解析国内本土直连网站 |
| **DoH (DNS over HTTPS)**| **HTTPS / TCP 443 端口** | 🟢 **工业级 TLS 加密**，伪装成普通网页浏览流量，无法被篡改 | **最推荐！** 用于海外防污染安全解析 |
| **DoT (DNS over TLS)** | **TLS / TCP 853 端口** | 🟢 **专有安全隧道**，加密强度极高，但 853 端口易被局部阻断 | 适合网络环境开阔的宽带或蜂窝网络 |
| **DoQ (DNS over QUIC)**| **QUIC / UDP 853/784 端口** | 🟣 **基于 HTTP/3**，抗网络抖动与丢包能力极强，零 RTT 握手 | 适合移动端 5G 与 Wi-Fi 频繁切换场景 |

## 二、国内直连 DNS vs 海外安全 DNS 黄金搭配清单

很多用户将所有 DNS 一股脑改成谷歌或 Cloudflare，导致国内淘宝、网易云音乐解析到了美国服务器，速度极慢。**科学的做法是“内外分治”**：

### 1. 国内直连 DNS 权威推荐（保障国内 App 极速加载）
- **阿里公共 DNS**：`223.5.5.5` / `223.6.6.6`（全国 BGP 节点，解析延迟低于 10ms）；
- **腾讯 DNSPod**：`119.29.29.29` / `182.254.116.116`（移动生态兼容极佳，防运营商劫持强）；
- **三大运营商本地 DNS**：直接继承系统自动分配的默认 DNS，获取离你物理距离最近的 CDN 节点。

### 2. 海外加密安全 DNS 权威推荐（保障海外网站防污染）
- **Cloudflare Security DNS (DoH)**：`https://1.1.1.1/dns-query`（全球 Anycast，隐私不留存日志）；
- **Google Public DNS (DoH)**：`https://dns.google/dns-query`（全球规模最大，解析库权威完备）；
- **阿里公共 DoH (国内加密备用)**：`https://dns.alidns.com/dns-query`（国内唯一被广泛信任的 DoH 接口）。

## 六、四大经典 DNS 报错与故障极速排查总表

当遇到 DNS 异常时，请对照下表自查：

| 具体 DNS 报错表现 | 底层技术网络归因 | 最核心诱发诱因 | 针对性快速解法 |
| :--- | :--- | :--- | :--- |
| **DNS Timeout (解析超时)** | 请求的数据包在网络半路丢失 | 配置的 DoH 服务器自身遭到运营商阻断，或网络不可达 | 换用国内阿里的 DoH，或切回系统默认的公共 DNS |
| **NXDOMAIN (域名不存在)** | 权威解析服务器明确返回无此域名 | 用户手动输入的网址拼写错误，或该子域名已被官方下线 | 仔细核对网址拼写，不要盲目怀疑小火箭客户端故障 |
| **SERVFAIL (解析失败)** | 本地 DNS 无法从上游权威服务器取回记录 | 本地 DNS 服务器遭到严重污染死锁，或根域名服务器异常 | 清空小火箭 DNS 缓存，更换其他备用加密 DNS |
| **纯 IP 能通，但输入网址打不开** | 域名解析环节完全死锁挂起 | 小火箭内配置了失效的私有 DNS，导致所有域名变盲人 | 将小火箭 DNS 恢复默认设置，或填入 `223.5.5.5` |

## 九、常见问题解答 (FAQ)

### Q1：Shadowrocket 的 DNS 到底有什么用？改 DNS 能提升网速吗？
**答**：DNS 的核心作用是把网址（如 `youtube.com`）翻译成服务器的数字 IP 地址。修改优质的 DNS 只能加快**首次打开网页那一瞬间的握手速度**，完全不能增加节点的物理下载带宽。

### Q2：什么是 DoH、DoT 和 DoQ？平时推荐开哪一个？
**答**：它们是新一代加密 DNS 协议：DoH 走 443 端口伪装成网页浏览，DoT 走 853 专有端口，DoQ 基于 QUIC 协议抗丢包更强。**日常首选推荐 DoH**（如 Cloudflare 或阿里 DoH），其穿透性与兼容性最佳。

### Q3：为什么不建议把所有 DNS 全换成纯海外的 Google (8.8.8.8)？
**答**：因为国内的绝大多数大型 App（微信、淘宝、抖音）依赖国内本地的 Anycast CDN 节点。如果使用纯海外 DNS，这些国内服务会被错误解析到跨大洋的欧美服务器，导致国内应用极度卡顿。

### Q4：输入纯 IP 能打开网页，但输入网址就提示无法连接怎么回事？
**答**：这是极为典型的 **DNS 解析死锁**！说明你的数据传输通道完全通畅，但域名无法被翻译为 IP。进入小火箭【设置】──►【DNS】，将自定义的杂乱 DNS 清空，恢复默认或填入 `223.5.5.5` 即可秒级解决。

### Q5：请求日志里经常跳出「DNS Timeout」怎么处理？
**答**：说明小火箭正在请求的那个 DNS 服务器本身失联或被本地宽带屏蔽。检查 DNS 列表中是否包含了被阻断的境外 53 端口地址，换用阿里云公共 DNS (`223.5.5.5`) 或稳定可达的 DoH 接口即可恢复。

### Q6：提示「NXDOMAIN」代表什么？是节点挂了吗？
**答**：**不是节点故障！** NXDOMAIN (Non-Existent Domain) 是互联网标准错误码，代表该域名在全世界的根 DNS 体系中都不存在；通常是因为你输入的网址拼写错误，或该服务已被官方注销下线。

### Q7：什么是 Local DNS Mapping？平时有什么实际用处？
**答**：它相当于手机本地的“Hosts 映射表”。允许你强制将某个域名死锁指向特定 IP，绕过任何远程查询。可用于加速经常被污染的海外服务（如 GitHub），或为家里的 NAS 绑定自定义内网域名。

### Q8：遇到小火箭 DNS 异常，最忌讳的操作是什么？
**答**：最忌讳“病急乱投医从网上随便抄一堆不知名私有 DNS 填进去”。这不仅无法修复故障，反而极易遭遇恶意的 DNS 钓鱼与中间人劫持；保持系统默认或选用阿里/腾讯等权威大厂 DNS 是最稳妥的底线。
