> **【💡 30 秒看懂：机场、客户端、节点与订阅的本质关系】**
> - **梯子 (Tizi)**：**通俗口语总称**，指一切实现科学上网的工具与方案；
> - **机场 (Airport)**：**服务提供商**，负责搭建海外服务器、维护线路并按月/年出售流量套餐；
> - **客户端 (Client)**：**本地连接管理软件**（如 Clash Verge Rev、Shadowrocket 小火箭、sing-box），本身是空壳，不自带任何网络节点；
> - **订阅链接 (Subscription)**：**配置传递钥匙**，机场提供的一串专属 URL，客户端通过它一键批量下载所有节点；
> - **节点 (Node)**：**具体连接入口**，分布在香港、日本、美国等地的远程服务器单项配置。
> 
> **一句大白话总结**：**“机场卖服务，订阅传配置，客户端管连接，节点跑流量，梯子是这套方案的口头叫法。”**

## 一、梯子和机场到底有什么区别？机场是不是梯子？

### 1. 概念层级不同：口语统称 vs 服务提供方
- **梯子**：是一个**广泛的概念统称**。不管你使用的是商业 VPN、自建 VPS 还是代理服务，只要能帮你访问海外网站，大家都习惯性地统称为“梯子”；
- **机场**：是梯子生态中的**“具体商业服务提供方”**。它专门负责采购机房服务器、拉设跨境专线（如 IPLC），并将这些资源打包成套餐卖给用户。

### 2. 为什么很多人说“买梯子”，实际买的是机场？
因为普通用户只关心最终能否打开 Google 或 ChatGPT，并不关心后台技术名词。用户在网站上付费下单购买的“每月 100GB 翻墙流量”，在行业内实际购买的就是**机场的订阅套餐**。

## 二、机场到底是什么？机场是一个软件吗？

### 1. 机场是一个平台服务，而不是一个软件！
很多新手常犯的一个错误是：在手机应用商店里拼命搜索“某某机场 App”。
**实际上，绝大多数标准机场根本没有自己的独立软件**。机场是一个网站平台，它的业务逻辑如下：

```text
 [机场网站后台]：注册账号 ──► 购买月付/年付套餐 ──► 获取专属【订阅链接】 ──► 结束（机场网站本身不负责代理网络）
```

### 2. 机场网站 vs 代理客户端区别表：

| 对比项目 | 机场官方网站 | 代理客户端 (如 Clash / 小火箭) |
| :--- | :--- | :--- |
| **运行环境** | 部署在云端服务器的 Web 网页 | 安装在用户手机或电脑本地的应用程序 |
| **核心功能** | 账号管理、套餐计费、充值续费、生成订阅 | 读取订阅、解析节点、分流规则、接管网络 |
| **能否直接上网** | ❌ **不能**（网页只用于配置与管理） | ❌ **不能**（空壳软件，需导入机场订阅） |
| **两者如何结合** | **从机场网站复制订阅 ──► 粘贴导入本地客户端 ──► 开启代理连接** |

## 三、客户端是什么？Clash 和 Shadowrocket 是机场吗？

### 1. 客户端是“纯净连接器”，绝非服务商
- **Clash / [Clash Verge Rev](/clash-verge-rev/)**：是开源跨平台的**规则分流代理客户端**；
- **Shadowrocket（小火箭）**：是 iOS 平台上经典的**网络代理管理软件**；
- **[sing-box](/tutorials/sing-box-config/) / v2rayN**：是跨平台高性能代理核心与 Windows 客户端。

> **📌 关键结论**：**Clash 不是机场，小火箭也不是机场！** 它们是由独立开源社区或开发者制作的通用工具，软件内部**默认没有任何服务器节点**。下载完客户端后，必须导入机场的订阅链接才能获取节点。

### 2. 自研客户端 vs 第三方开源客户端对比：

| 客户端类别 | 代表形式 | 优点与长处 | 缺点与潜在短板 |
| :--- | :--- | :--- | :--- |
| **第三方开源客户端**<br>*(行业绝对主流)* | Clash Verge Rev、Shadowrocket、sing-box | 纯净无广告、开源透明、支持导入多家机场、分流规则极强 | 需要新手花 3 分钟学习复制导入订阅的步骤 |
| **机场自研定制 App**<br>*(少数提供)* | 某机场专用的 一键登录 App | 登录账号直接连，免去复制订阅步骤 | 无法导入其他机场，软件更新缓慢，透明度较低 |

## 四、节点是什么？为什么一个机场会有几十个节点？

### 1. 节点（Node）的真实面貌
一个节点在配置文件里本质上是一串服务器连接参数：
- **服务器地址**（如 `hk01.example.com`）；
- **端口号**（如 `443`）；
- **协议与加密方式**（如 `VLESS + Reality`、`Trojan` 或 `Shadowsocks`）；
- **用户专属密钥**（UUID / Password）。

### 2. 为什么机场要提供大量不同地区的节点？

```text
                               【机场节点分类与用途对照】
 ┌──────────────────────────────┬──────────────────────────────┬──────────────────────────────┐
 │ 节点地区与标识               │ 典型物理位置                 │ 最适合的业务场景             │
 ├──────────────────────────────┼──────────────────────────────┼──────────────────────────────┤
 │ 🇭🇰 **香港节点 (HK)**          │ 物理距离最近 (延迟 30~60ms)  │ 日常秒开网页、外贸邮件、办公沟通│
 │ 🇯🇵 **日本节点 (JP)**          │ 亚太优质机房 (延迟 60~90ms)  │ 访问 GitHub、看动漫日剧、游戏联机│
```

## 五、订阅是什么？为什么说订阅链接千万不能泄露？

### 1. 订阅（Subscription）是批量管理节点的桥梁
如果机场有 80 个节点，如果让用户手动一个个输入服务器 IP、端口和密码，配置一台电脑需要半小时，且一旦机房 IP 更换，全部配置立刻作废。
- **订阅链接的魔力**：机场把这 80 个节点的全部配置加密打包成一个固定的 HTTPS 链接。客户端只要导入这个链接，就会**自动下载所有节点**；当机场维护更换线路时，客户端只需点击“更新”，所有节点**秒级全自动同步**。

### 2. 🔒 订阅链接泄露有多危险？
订阅链接中包含你的**专属鉴权 Token**：

```text
 伪代码示意：https://sub.airport.com/api/v1/client/subscribe?token=9f8e7d6c5b4a...
                                                             └──── 等同于免密提权凭证 ────┘
```

- **泄露后果**：任何人拿到你的订阅链接，都可以直接导入他们自己的客户端使用，**瞬间耗尽你的套餐流量**；若多地同时连接，还会导致你的账号因“违规共享”被机场系统封禁；
- **补救措施**：若不慎泄露，立刻登录机场后台点击 **【重置订阅链接 / Reset Token】**，旧链接将瞬间失效。

## 六、套餐与订阅、客户端的生命周期关系

新手常常困惑于“换了手机/换了软件，我的套餐还在不在”，以下一张表讲透它们之间的解耦关系：

| 发生的变更操作 | 对机场账号与套餐的影响 | 对本地客户端的影响 | 正确处置方式 |
| :--- | :--- | :--- | :--- |
| **手机上卸载了小火箭 App** | **毫无影响**（套餐仍在机场云端） | 本地配置被清空 | 重新下载 App，把订阅链接再导入一次即可 |
| **电脑从 Clash 换成 sing-box** | **毫无影响**（流量额度不变） | 新客户端为空 | 将原有的订阅链接直接粘贴进新客户端 |
| **机场套餐到期未续费** | 账号被暂停服务 | 客户端内的旧节点将**全部测速超时** | 在机场后台充值续费，随后在客户端点击“更新订阅” |
| **购买了第二家新机场的套餐** | 拥有两个独立服务商账户 | 可在同一个客户端内**同时导入两条订阅** | 在客户端内自由切换两家机场的不同节点 |

## 七、节点倍率与测速延迟：新手必须纠偏的两个误区

### 误区一：节点名字里的“倍率 (0.5x / 1.0x / 2.0x)”代表网速？
- **真相**：**倍率完全是“扣费倍率”，与网速快慢没有任何直接关系！**
  - **0.5x 节点**：下载 1GB 实际文件，仅扣除你账户 0.5GB 流量（适合大文件下载）；
  - **1.0x 节点**：标准节点，下载 1GB 扣除 1GB 流量；
  - **3.0x 节点**：昂贵的高级独享专线，下载 1GB 扣除 3GB 流量。

### 误区二：客户端里“URL Test 延迟”越低，下载速度就越快？
- **真相**：测速显示的 50ms 仅代表**握手响应快慢**（打开网页的瞬间反应）；而看 4K 视频或下载大文件，取决于节点的**总出口带宽大小与持续丢包率**。

## 八、机场、客户端、节点与订阅全维度协作总表

| 核心组件 | 物理所在位置 | 谁来提供 / 维护 | 核心任务 | 出现问题时的典型表现 |
| :--- | :--- | :--- | :--- | :--- |
| **机场平台** | 云端 Web 服务器 | 商业服务商团队 | 计费、结算、运维专线与提供订阅 | 机场官网打不开、无法登录充值 |
| **订阅链接** | 动态 API 接口 | 机场系统自动生成 | 向客户端分发与同步节点清单 | 客户端提示“订阅更新失败 / 网络错误” |
| **客户端软件** | 用户本地手机/电脑 | 开源社区 / 独立开发者 | 接管系统流量、解析配置、智能分流 | 软件闪退、无法打开“系统代理开关” |
| **服务器节点** | 海外机房物理机器 | 机场机房运维人员 | 承担加密隧道传输、提供落地出口 IP | [节点列表全部超时全红 (Timeout)](/issues/clash-nodes-timeout/) |
| **分流规则** | 客户端内置策略组 | 客户端规则引擎 | 区分国内流量（直连）与国外流量（代理） | 国内应用变慢或特定海外网站打不开 |

## 十一、常见问题解答 (FAQ)

### Q1：梯子和机场到底有什么区别？
**答**：梯子是中文互联网对所有翻墙手段的通俗统称；而机场是具体的服务提供商。机场负责架设服务器与线路，并向用户提供节点订阅，属于梯子生态中的核心服务供应方。

### Q2：机场是不是一个手机 App 软件？
**答**：绝大多数情况下不是。机场是一个提供网络服务的平台网站。购买机场后，你需要使用独立的第三方客户端软件（如 Clash、小火箭）来导入机场提供的订阅链接。

### Q3：为什么我下载了 Clash / 小火箭后，里面没有节点？
**答**：因为这些客户端是开源社区开发的纯净连接工具，本身不附带任何服务器节点。你必须从机场获取订阅链接并导入软件中，才能拉取到可用节点。

### Q4：为什么买了 Shadowrocket（小火箭）以后还需要买机场？
**答**：购买小火箭只是购买了一款运行在 iPhone 上的“网络连接管理器软件”；而要真正连通海外网络，必须向机场购买“网络节点与跨境数据流量服务”。

### Q5：Clash 是机场吗？
**答**：不是。Clash 是一个开源的规则分流代理引擎与客户端协议标准，负责根据分流规则调度你的网络请求，它自身不售卖任何网络节点。

### Q6：订阅链接和节点有什么区别？
**答**：节点是具体某台服务器的连接参数（如一台香港服务器）；订阅链接则是一个把几十个节点打包在一起的汇总分发网址，客户端通过订阅链接可以一键导入并自动更新所有节点。

### Q7：订阅链接泄露了会怎么样？
**答**：他人可以直接将你的订阅链接导入他们的软件，白嫖盗用你的套餐流量；多地同时使用还可能导致你的机场账号被系统封禁。泄露后需立即在机场后台重置订阅。

### Q8：节点名字里的“倍率”是什么意思？
**答**：倍率代表扣除流量的比例。例如使用 0.5x 节点消耗 1GB 仅扣除 500MB 套餐额度；使用 2.0x 节点消耗 1GB 会扣除 2GB 额度，它与网速快慢无关。

### Q9：换了一台新电脑，原来的机场还能用吗？
**答**：完全可以。在新的电脑上安装好客户端，把原先机场后台的订阅链接再次复制导入一遍即可，套餐流量在云端跨设备共享。

### Q10：换了一个新的客户端软件，原先买的机场套餐会失效吗？
**答**：不会。机场套餐绑定在你的机场账户上，只要新客户端支持该订阅格式（如 Clash、sing-box 格式），直接导入相同订阅链接即可继续使用。

### Q11：节点测速延迟越低，就代表看视频越快吗？
**答**：不一定。测速显示的延迟（ms）只代表点击网页第一瞬间的响应灵敏度；看高清 4K 视频的流畅度主要取决于节点的**总出口带宽大小与持续丢包率**。

### Q12：为什么有时候节点测速正常，但依然打不开网页？
**答**：可能原因包括客户端的“系统代理”开关未打开、分流模式误选为了“Direct 直连”、或者本地 DNS 发生解析异常，可参考 [节点超时与网络故障排查专栏](/issues/clash-nodes-timeout/)。
