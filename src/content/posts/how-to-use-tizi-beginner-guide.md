> **【💡 第一次使用梯子，新手只看这 6 步黄金流程】**
> 1. **确认服务类型**：明确你拿到的是“商业一键 VPN 账号”还是“机场订阅链接”；
> 2. **下载对应客户端**：Windows/Mac 推荐 [Clash Verge Rev](/clash-verge-rev/)，安卓推荐 Clash Meta，iPhone 推荐 Shadowrocket（小火箭）；
> 3. **获取专属订阅链接**：在机场用户后台复制你的 HTTPS 专属订阅 URL（🔒 严禁公开发送他人）；
> 4. **导入客户端并刷新**：打开客户端配置/订阅管理，粘贴链接并点击“下载/更新”，拉取全部节点；
> 5. **选择节点并开启代理**：在节点列表选择一个绿色低延迟节点（如香港或日本），开启 **【系统代理 (System Proxy)】** 并选择 **【规则模式 (Rule)】**；
> 6. **浏览器测试验证**：打开海外目标网站（如 Google / ChatGPT）确认页面秒开，国内微信、百度直连不卡顿。

## 一、第一步：判断你使用的是哪种服务模式？

在下载软件前，必须先看清你手里的产品类型：

| 服务模式 | 典型特征与交付物 | 用户操作流程 | 最适合人群 |
| :--- | :--- | :--- | :--- |
| **机场 + 开源客户端模式**<br>*(中文圈 90% 主流)* | 拿到的是一串 **HTTPS 订阅链接** 或二维码，没有官方独立 App | 需自行下载 Clash/小火箭等客户端，把订阅导入后选择节点 | **追求高网速、低延迟、智能分流与高性价比的国内用户** |
| **商业一键 VPN App 模式**<br>*(如 NordVPN 等)* | 拿到的是 **用户名 + 密码**，官方提供专属安装包 | 下载官方 App 登录账号，点击屏幕中央的大圆圈 Connect 按钮即可 | 长期身处海外、不愿研究分流规则的留学生或外籍人士 |

> 📌 *注：本文重点讲解目前最主流、体验最好的 **“机场 + 开源客户端”** 标准流程。如果你还不清楚机场和 VPN 的区别，可先阅读 [《梯子是什么？》基础认知科普](/tizi/)。*

## 三、第三步：获取你的专属订阅链接

1. 登录你所购买的机场用户后台；
2. 找到 **【仪表盘 / 订阅中心 / 节点订阅】** 页面；
3. 点击 **【复制订阅链接】**（通常优先选择 *Clash 订阅* 或 *通用订阅*）；
4. **🔒 订阅安全 Warning**：订阅链接是你的专属身份凭证，**切勿截图发给朋友或公开发布在论坛**，否则他人可以免密盗用你的流量配额。

```text

 https://api.your-airport-domain.com/api/v1/client/subscribe?token=a1b2c3d4e5f6g7h8...
                                                                └───── 专属加密凭证 ─────┘
```

## 四、第四步：将订阅导入客户端并拉取节点

无论在手机还是电脑上，导入逻辑完全相通：

```text
 打开客户端 ──► 找到【配置/订阅/Profiles】 ──► 粘贴订阅 URL ──► 点击【保存/下载/Import】 ──► 看到节点列表加载成功
```

- **扫码导入（手机端最快）**：如果机场后台提供了订阅二维码，在手机客户端中点击右上角【+】号 ──► 选择【扫描二维码】直接对准屏幕扫描即可；
- **URL 粘贴导入（电脑端最准）**：在 Clash Verge Rev 中点击左侧 **【订阅 (Profiles)】** ──► 顶部输入框粘贴链接 ──► 点击 **【导入 (Import)】**。

## 五、第五步：节点选择与延迟测试核心技巧

导入成功后，切换到 **【代理 (Proxies)】** 页面，你将看到数十个甚至上百个节点：

```text
 [节点测速 (URL Test)] ──► 筛选绿色低延迟 (如 50ms~120ms) ──► 避开超时红字 (Timeout) ──► 点击选中目标节点
```

### 节点选择六大指标评估对照表：

| 评估指标 | 真实含义与影响 | 新手常见误区与避坑指南 |
| :--- | :--- | :--- |
| **延迟 (Latency / ms)** | 数据包往返响应灵敏度（50~120ms 为极佳） | ❌ **误以为延迟最低下载速度一定最快**（延迟只管网页秒开，速度看带宽） |
| **节点地区 (Region)** | 目标服务器物理出海口（香港/日本/美国等） | ❌ **误以为美国节点看视频最快**（看网页香港更顺畅，ChatGPT 选美/日/新更稳） |
| **倍率 (Multiplier / x)** | 消耗账户流量的计算倍数（如 1.0x / 0.2x / 3.0x） | ❌ **误以为 3.0x 代表 3 倍网速**（3.0x 意味着下载 1GB 扣除 3GB 账户流量） |
| **线路类型 (Line Type)** | BGP 中继、IPLC 专线或直连普通线路 | 建议日常办公优先选用标有 *IPLC / IEPL / 专线* 的节点（晚高峰不卡顿） |

## 六、第六步：开启连接与分流模式选择 (System Proxy vs TUN, Rule vs Global)

这是决定网络体验的最关键一步：

```text
                               【分流模式 (Routing Mode) 怎么选？】
                                                │
                 ┌──────────────────────────────┴──────────────────────────────┐
                 │                                                             │
      🟢 规则模式 (Rule / 智能分流)                                 🔴 全局模式 (Global / 强制代理)
  - 国内网站 (百度/淘宝/微信) 走本地直连                         - 手机/电脑上的所有流量全部走海外节点
  - 国外被墙网站 (Google/YouTube) 走代理                         - 用于临时测试节点连通性或特殊排障
  - ✅ 【日常 95% 时间强烈推荐默认开启】                         - ⚠️ 【长时间开启会导致国内应用变慢卡顿】
```

### System Proxy (系统代理) vs TUN (虚拟网卡模式) 差异：

| 模式名称 | 工作原理 | 适用场景 | 新手建议 |
| :--- | :--- | :--- | :--- |
| **系统代理 (System Proxy)** | 告知操作系统和浏览器“请将 Web 流量转发给客户端” | 网页浏览、看视频、日常轻办公 | **新手首选，开启即可使用** |
| **TUN 虚拟网卡模式** | 在系统内核创建虚拟网卡，接管所有底层网络数据包 | 游戏联机加速、终端命令行 (Git/Docker)、不遵循系统代理的特定软件 | 进阶功能，有特定非网页代理需求时再开启 |

## 七、四大操作系统实操步骤速查卡

### 1. 📱 Android 安卓手机使用 7 步法
1. 安装 **Clash Meta for Android** 或 **sing-box**；
2. 打开 App ──► 点击【配置 (Profiles)】──► 点击右上角【+】号；
3. 选择【URL 导入】──► 粘贴机场订阅链接 ──► 点击右上角【保存】并下载；
4. 返回首页，点击【已停用】大按钮开启连接；
5. 首次开启系统会弹出 **“网络连接请求 / 允许创建 VPN”** 提示 ──► 点击 **【确定】**；
6. 在【代理】页面选择【规则模式】，挑选一个绿色香港或新加坡节点；
7. 打开手机 Chrome 访问 Google 测试。

### 2. 🍏 iPhone / iPad 苹果设备使用 8 步法
1. 退出国区 Apple ID，在 App Store 登录外区账号下载 **Shadowrocket（小火箭）**；
2. 打开小火箭 ──► 点击右上角 **【+】** 号 ──► 类型选择 **【Subscribe (订阅)】**；
3. 在 URL 栏粘贴机场订阅链接 ──► 点击右上角 **【完成】**；
4. 订阅将自动刷新并展示出全部节点列表；
5. 点击最上方的 **【未连接】** 开关 ──► 首次连接弹出 **“允许添加 VPN 配置”** ──► 输入 iPhone 锁屏密码确认；
6. 全局路由默认保持为 **【配置 (Config)】**（即规则分流模式）；
7. 挑选一个连通性最好的节点即可畅快使用。

### 3. 💻 Windows 电脑实操 6 步法
1. 从官网 Releases 下载安装 [Clash Verge Rev Windows 安装包](/clash-verge-rev/)；
2. 启动软件 ──► 点击左侧菜单 **【订阅 (Profiles)】**；
3. 顶部输入框粘贴订阅链接 ──► 点击 **【导入 (Import)】**；
4. 鼠标右键点击导入的订阅卡片 ──► 选中该配置（卡片显示蓝色高亮）；
5. 点击左侧 **【设置 (Settings)】** ──► 开启 **【系统代理 (System Proxy)】** 开关；
6. 切换到左侧 **【代理 (Proxies)】** ──► 模式选 **【Rule】** ──► 选一个节点开始上网。

### 4. 🍎 macOS 苹果电脑实操 6 步法
1. 下载安装 **Clash Verge Rev for macOS**（M 系列芯片选 aarch64.dmg，Intel 选 x64.dmg）；
2. 拖入 Applications 打开（若提示安全性阻止，在系统设置【隐私与安全性】中点击“仍要打开”）；
3. 导入机场订阅链接并激活；
4. 开启软件界面的 **【系统代理】** 开关；
5. 首次开启若需安装服务模式（Service Mode），点击【允许】并输入 Mac 开机密码；
6. 代理模式保持 **【Rule】** 即可。

## 八、连接后如何验证是否真正成功生效？

不要只看到客户端显示“Connected”就认为万事大吉，请执行以下标准验证：

```text
1. 打开浏览器无痕窗口输入：https://www.google.com ──► 能够秒开且无卡顿 (证明基础 Web 代理畅通)
   ↓
2. 访问公共 IP 查询站 (如 ipinfo.io 或 myip.la) ──► 显示的 IP 地址为海外机房 (证明出口已成功切换)
   ↓
3. 打开国内网页 (如 www.baidu.com) ──► 同样秒开 (证明规则模式智能分流生效，国内没有被绕道减速)
```

## 九、新手最容易犯的 12 个常见错误与避坑指南

1. ❌ **买了机场服务却不知道还要下载客户端软件**；
2. ❌ **花钱买了 Shadowrocket 小火箭软件，以为自带翻墙网络直接点连接**；
3. ❌ **导入订阅后忘记点击“激活/选中”该配置**；
4. ❌ **Windows 电脑打开了客户端，但忘了打开【系统代理 (System Proxy)】开关**；
5. ❌ **在代理模式中错误地选成了【Direct (直连)】，导致所有流量根本没走节点**；
6. ❌ **误开【Global (全局模式)】后抱怨国内网银、微信小程序和淘宝打不开**；
7. ❌ **订阅链接过期或机场更换了服务器，长达数月从未点击过“更新订阅”**；
8. ❌ **电脑关闭客户端前没有正常关闭系统代理，导致退出软件后电脑彻底断网**；
9. ❌ **一看到节点延迟稍微变大，就每隔 10 秒神经质般频繁手动切换节点**；
10. ❌ **在公司内网办公电脑上私自安装代理，触发企业 DLP 安全网关警告**；
11. ❌ **轻信网络上的“免费公益节点打包”，导致个人重要账号被中间人窃取**；
12. ❌ **遇到打不开网页就立刻重装操作系统或格式化网络设置**。

## 十、常见故障 5 分钟极速自检与分流导航

遇到网络不通时，请按顺序排查：

```text
 1. 客户端图标是否正常运行？ (排查软件是否崩溃退出)
    ↓
 2. 节点列表测速是否全部显示“Timeout / 超时红字”？ 
    ├── 是全部超时 ──► 转入 [Clash 节点全红排查专题](/issues/clash-nodes-timeout/) (多为订阅过期或本地网络受限)
    └── 仅单个超时 ──► 鼠标换选另一个绿色节点即可
    ↓
 3. Windows 关闭客户端后电脑网页全部无法打开？
    └── 属于系统代理残留 ──► 进入 Windows 设置 ──► 网络和 Internet ──► 代理 ──► 将【使用代理服务器】手动关闭
    ↓
 4. 节点正常、Google 能开，但 ChatGPT 提示打不开或报错？
    └── 属于节点 IP 被 AI 服务风控 ──► 参考 [ChatGPT 打不开排查指南](/chatgpt/cannot-open/)
```

## 🔒 凭据与隐私安全特别警示

> **核心安全准则**：
> - **严守订阅链接隐私**：订阅 URL 内嵌授权 Token，泄露即等同于账号密码泄露；
> - **警惕异常权限申请**：正规网络代理工具仅需系统的网络扩展/VPN 接口权限，**绝不需要获取通讯录、相册、短信或无障碍辅助功能权限**；
> - 官方帮助中心与合规专线推荐仅限：**[2026 翻墙机场与 IPLC 专线排行榜](/recommend/airport/)**。

## 十二、常见问题解答 (FAQ)

### Q1：第一次使用梯子，最基本的步骤是什么？
**答**：准备硬件设备 ──► 购买机场服务获取专属订阅链接 ──► 下载安装适配客户端（如 Windows 用 Clash Verge，iOS 用小火箭） ──► 导入订阅并下载节点 ──► 开启系统代理与规则模式 ──► 打开 Google 测试。

### Q2：为什么我下载了 Clash / 小火箭后，里面空空如也连不上网？
**答**：因为这些客户端只是纯净的开源连接工具，本身不包含任何服务器节点。你需要从合规的机场服务商处获取“订阅链接”，导入软件中拉取节点后才能正常使用。

### Q3：买完机场服务后，直接用手机浏览器能翻墙吗？
**答**：不能。机场是远程网络服务提供方，手机浏览器不具备解析加密代理协议的能力。必须借助客户端（如 Shadowrocket）作为桥梁，将手机的网络流量中继转发给机场节点。

### Q4：订阅链接怎么导入到客户端里？
**答**：在机场后台复制订阅链接 ──► 打开客户端进入【Profiles / 订阅】页面 ──► 在输入框中粘贴该 URL ──► 点击【Import / 下载 / 保存】即可自动加载全部节点。

### Q5：第一次使用应该选哪个国家或地区的节点？
**答**：日常浏览网页与看 4K 视频，推荐优先选择地理距离近的 **中国香港 (HK)、日本 (JP)、新加坡 (SG)** 节点（延迟低、速度快）；如果专门为了访问特定海外服务或 AI 工具，可选择 **美国 (US)** 节点。

### Q6：节点列表里的“延迟 (Ping)”越低，看视频就越快吗？
**答**：不一定。延迟只代表数据包往返的响应灵敏度，决定了打开网页的第一瞬间是否迅速；而看高清视频的流畅度主要取决于节点的**总带宽上限与持续丢包率**。

### Q7：什么是“规则模式 (Rule)”？为什么强烈推荐它？
**答**：规则模式能够自动识别网络请求：访问国内网站（百度、淘宝、微信）直接走本地宽带直连；访问海外受限网站（Google、YouTube）才自动走代理节点。既省流量，又保证国内应用不被减速。

### Q8：什么是“全局模式 (Global)”？什么时候用它？
**答**：全局模式会强制将手机或电脑上的所有网络流量全部通过海外节点转发。通常仅在某些小众国外应用在规则模式下无法识别、或排查规则故障时临时开启，日常不建议长开。

### Q9：System Proxy（系统代理）和 TUN 模式有什么区别？
**答**：系统代理主要接管遵循系统设置的浏览器和通用应用，使用最简便；TUN 模式是在系统内核创建虚拟网卡，能接管命令行终端、游戏客户端等底层数据包。新手日常建议首选系统代理。

### Q10：退出客户端软件后，为什么电脑突然连国内网页也打不开了？
**答**：这是因为直接强退客户端导致 Windows 系统的代理设置没有被正常还原。手动进入 Windows 设置 ──► 【网络和 Internet】 ──► 【代理】 ──► 将【使用代理服务器】关闭即可秒级恢复。

### Q11：手机和电脑可以共用同一个机场订阅链接吗？
**答**：可以。将同一个订阅链接分别导入手机和电脑客户端即可。但请注意服务商套餐的“同时在线设备数 (IP 限制)”，避免超出限制触发临时风控。

### Q12：为什么节点列表过了一段时间会全部显示超时或红色？
**答**：常见原因包括机场服务器节点 IP 进行了例行维护更新、本地网络发生波动阻断，或账户流量用尽。尝试在客户端右键点击订阅执行 **【更新订阅 (Update)】** 通常可解决。

### Q13：开启梯子后，可以玩国服游戏或看国内网易云音乐吗？
**答**：只要保持在 **【规则模式 (Rule)】** 下，客户端会自动放行国内游戏与音乐应用走直连宽带，完全不受任何影响。

### Q14：iPhone 开启小火箭时提示“添加 VPN 配置”安全吗？
**答**：安全。这是 iOS 操作系统为网络扩展程序提供的标准安全确认机制，输入锁屏密码允许即可。

### Q15：节点名字里的“0.5x”、“1.0x”、“2.0x”是什么意思？
**答**：这代表**流量计费倍率**。使用 0.5x 节点下载 1GB 仅扣除 500MB 账户流量；使用 2.0x 节点下载 1GB 则扣除 2GB 流量，它不代表网速倍率。

### Q16：如何最稳妥地开始我的第一次使用体验？
**答**：先阅读本文理清流程 ──► 电脑下载 Clash Verge Rev / 手机下载小火箭 ──► 挑选一个优质专线机场导入订阅 ──► 开启规则模式，即刻享受畅通无阻的全球网络。
