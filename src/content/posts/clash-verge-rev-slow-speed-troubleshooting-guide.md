> **【💡 30 秒极速分诊：Clash Verge Rev 速度慢到底慢在哪里？】**
> - **第一核心纠偏**：**“网络速度慢”绝不是单一的指标！** 延迟 (Latency)、带宽 (Bandwidth)、丢包率 (Packet Loss) 和抖动 (Jitter) 是四个完全不同的物理维度。**节点旁边显示的 30ms 绝不代表下载速度快**，它仅仅反映握手往返耗时；
> - **六类典型“慢”现象极速对号入座**：
>   1. **网页秒开，但下载大文件极慢（仅几百 KB/s）** ──► 属于**带宽瓶颈**或节点出口限速，需切换高带宽大流量节点；
>   2. **测速显示百兆带宽，但看 YouTube 依然频繁转圈缓冲** ──► 属于**丢包与抖动严重**，TCP 拥塞控制强行降速；
>   3. **白天飞快、一到晚上 8 点后断崖式卡顿** ──► 典型的**晚高峰国际骨干网拥堵**或机场入口服务器过载超售；
>   4. **打游戏延迟高且频繁瞬移卡顿** ──► 属于**路由绕路与 UDP 丢包**，需改用游戏专用专线节点并开启 [TUN 模式](/clash-verge-rev/tun/)；
>   5. **连网线飞快，一用 Wi-Fi 速度暴跌** ──► 纯粹属于**本地 2.4GHz 无线信道干扰**，与代理节点无关；
>   6. **绝大多数网站飞快，只有特定一个网站卡死** ──► 属于目标网站的海外 CDN 边缘节点对当前代理 IP 限速或分流误判。

## 二、四大核心网络指标深度辨析：为什么“低 ms 并不代表速度快”？

很多初学者最大的误区就是盲目追求代理面板里显示的“最低毫秒数”：

```text
 ┌─────────────────────────────────────────────────────────────────────────────────────────────┐
 │                               【四大性能指标物理含义深度剖析】                              │
 ├──────────────────┬──────────────────────────────┬───────────────────────────────────────────┤
 │ 核心物理指标     │ 通俗直白解释                 │ 对日常上网的具象决定性影响                │
 ├──────────────────┼──────────────────────────────┼───────────────────────────────────────────┤
 │ **1. Latency**   │ 数据包往返一个来回的时间     │ 决定网页点开的“瞬时反应快慢”，对文字秒开至关重要 │
 │ **2. Bandwidth** │ 单位时间内能搬运的最大数据量 │ 决定“下载大文件与看 4K 视频上限”，与延迟完全是两码事 │
 │ **3. Packet Loss**| 数据包在半路丢失的百分比    │ 丢包超 5% 就会导致视频卡死、网页假死、游戏频繁瞬移 │
 │ **4. Jitter**    │ 延迟波动的剧烈程度（不稳定度）| 延迟在 30ms 与 300ms 之间反复跳跃，极度破坏实时体验 │
 └──────────────────┴──────────────────────────────┴───────────────────────────────────────────┘
```

### 为什么 20ms 的香港节点看视频卡，120ms 的美国节点看 4K 却秒开？
- **20ms 香港节点**：物理距离虽近、握手延迟极低，但机房如果只买了 20Mbps 廉价小水管，百人共用瞬间满载；同时公网丢包高达 15%，导致视频流反复重传卡顿；
- **120ms 美国节点**：虽然跨越太平洋带来 120ms 的物理延迟，但其机房配备了 10Gbps 独立专线大带宽，丢包率低于 0.1%，视频缓冲条瞬间拉满。
- **黄金选点法则**：日常查资料、办公、敲代码选 **低延迟香港/日本节点**；看 Netflix、YouTube 4K 和下载大文件选 **大带宽专线或欧美节点**。

## 四、本地网络瓶颈排查：Wi-Fi 干扰与手机热点交叉验证

排查速度问题，**最容易被忽视的元凶往往是身边的路由器 Wi-Fi**：

```text
 1. 【2.4GHz 频段与信道干扰死锁】：
    - 若电脑连接的是老旧的 2.4GHz Wi-Fi，受到微波炉、蓝牙和邻居路由器的严重同频干扰，真实吞吐量可能暴跌至 5Mbps 以下，丢包率飙升；
    - 解决：在路由器后台强制连接 5GHz / 6GHz 频段，或直接插网线测试。

 2. 【手机 4G/5G 热点一键对照法（极高诊断价值）】：
    - 关掉电脑 Wi-Fi，用数据线或无线热点连接手机网络，再次测速；
    - 若热点环境下速度瞬间恢复几十 MB/s，说明**你的机场节点完好，问题 100% 出在家庭光猫、宽带运营商国际出口或路由器本身**。
```

## 六、关于节点“倍率”的重大认知纠偏

在订阅配置中经常看到 `香港 01 [2.0x]` 或 `美国 02 [0.2x]` 的字样：

```text
 ⚠️ 【极其常见的新手误区】：
 “2.0x 节点是不是代表速度比 1.0x 快两倍？0.2x 节点是不是速度慢 5 倍？”
 
 真实技术含义：
 - 【倍率完全属于计费规则，绝不代表物理网速上限】！
 - 2.0x 代表你实际消耗 1GB 流量，机场后台扣除 2GB 配额（通常因为该节点租用了极其昂贵的高品质独享专线）；
 - 0.2x 代表你消耗 1GB 流量，后台仅扣除 200MB（通常为廉价公网中转节点）；
 - 很多 0.2x 节点的空闲带宽非常充沛，非晚高峰时看 4K 视频一样秒开，非常适合用来跑大流量下载！
```

## 九、常见问题解答 (FAQ)

### Q1：为什么节点旁边显示的延迟只有 30ms，但实际下载速度却只有几百 KB/s？
**答**：因为 30ms 仅代表你的电脑与该节点服务器之间的握手往返延迟极低；而下载速度取决于该节点配备的物理带宽大小以及当前是否有大量用户在并发抢占通道。

### Q2：看 YouTube 4K 视频老是卡顿缓冲，应该重点排查什么？
**答**：重点排查**丢包率 (Packet Loss) 与晚高峰拥堵**。公网跨境传输一旦出现 5% 以上的丢包，视频流传输协议就会启动退避重传导致断流；切换到丢包率极低的专线节点或冷门地区大带宽节点即可解决。

### Q3：为什么白天看视频非常流畅，一到晚上 8 点至 11 点就卡得无法使用？
**答**：这是极为典型的“国际出口晚高峰拥塞”：全国海量用户集中访问外网，导致运营商骨干网和普通中转机房入口拥堵严重；建议在晚高峰改用抗拥堵的 IPLC 专线节点，或避开拥挤的热门香港一号节点。

### Q4：节点倍率（如 2.0x 或 0.5x）代表什么？倍率越高速度越快吗？
**答**：**不代表速度！** 倍率纯粹是机场的计费倍数（2.0x 代表用 1G 扣除 2G 流量）。虽然高倍率节点通常成本较高、人数较少，但不代表物理速度绝对翻倍；很多 0.2x 节点在非高峰期同样能跑满几百兆。

### Q5：手机热点测速很快，但电脑连家里 Wi-Fi 却非常慢是什么原因？
**答**：说明机场节点完全正常，瓶颈 100% 在家里的 Wi-Fi 信号上！通常是因为电脑连入了 2.4GHz 干扰严重的频段、路由器散热不良降频，或家庭光猫 NAT 性能耗尽；切换到 5GHz Wi-Fi 或插网线即可恢复。

### Q6：开启 TUN 模式或者全局模式 (Global) 会让速度变快吗？
**答**：**不会！** TUN 只是接管流量的虚拟网卡，Global 只是把所有国内流量也强制走代理，两者都不会为节点增加物理带宽；反而开启 Global 会导致国内软件全线变卡。

### Q7：打游戏时延迟很低但角色频繁“瞬移/丢操作”是怎么回事？
**答**：属于典型的**网络丢包与抖动 (Jitter)**。实时网络对局极其依赖平稳无损的 UDP 数据传输，一旦中间链路发生丢包就会导致操作数据丢失；在客户端中开启 TUN 模式并选用标有“游戏专线/低丢包”的节点。

### Q8：怎么在 Clash Verge Rev 中确认某个视频究竟走了哪个节点？
**答**：打开左侧的【连接 (Connections)】实时监控面板，开始播放视频。在列表中找到以 `googlevideo.com` 等视频流域名的连接行，点击展开即可直观查阅当前实际分流指派的策略组与具体节点。
