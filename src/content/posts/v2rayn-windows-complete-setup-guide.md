## 四、节点选择与连通性测试：Tcping 假延迟 vs 真连接延迟

这是 90% 的新手最容易被忽悠的技术分水岭：

| 测速类型 | 测试原理与物理网络行为 | 结果数值代表的含义 | 对翻墙可用性的真实参考价值 |
| :--- | :--- | :--- | :--- |
| **测试服务延迟 (Tcping)** | 仅向节点服务器的 IP 和端口发送简单的 TCP SYN 探测包 | 仅代表物理中转机房的握手耗时（通常几十 ms） | 🔴 **参考价值极低！** 即使节点被封或账号欠费，Tcping 依旧显示绿色假延迟！ |
| **测试服务真连接延迟 (True Delay)** | **真枪实弹通过节点加密隧道向 Google 发起 HTTP GET 请求** | **代表完成整个握手、加密通信并取回网页真实延迟** | 🟢 **绝对权威！** 只有测出有效毫秒数（如 180ms）的节点，才是能真正翻墙的节点！ |
| **测试服务真连接测速 (Speed Test)** | 实际从远端拉取一个测试数据包测算瞬时下行带宽 | 直观显示该节点的真实吞吐速度（如 35MB/s） | 🟣 **判断晚高峰与 4K 播放能力的终极依据** |

### 快速测试与激活节点快捷键：
- **全选节点**：按键盘 `Ctrl + A`；
- **批量测试真延迟**：按键盘快捷键 **`Ctrl + R`**（程序会自动并发向 Google 发起真实测试，报 `-1` 或 `Timeout` 的为失效节点）；
- **按真延迟自动排序**：点击表头的【真连接延迟】列，延迟最低的绿色节点会自动排在第一行；
- **激活选中节点**：鼠标单击该节点，按下键盘 **`Enter (回车键)`**，节点名称左侧出现蓝色或勾选标记即代表设为当前活动节点！

## 五、两大网络接管模式深度解析：系统代理 vs TUN 虚拟网卡

在 v2rayN 底部任务栏或托盘图标右键菜单中，决定流量去向的核心开关：

```text
 ┌─────────────────────────────────────────────────────────────────────────────────────────────┐
 │                               【系统代理 vs TUN 虚拟网卡技术对比】                          │
 ├──────────────────────┬──────────────────────────────┬───────────────────────────────────────┤
 │ 核心技术参数         │ 模式 A：系统代理 (System Proxy) │ 模式 B：TUN 虚拟网卡模式 (TUN Mode)    │
 ├──────────────────────┼──────────────────────────────┼───────────────────────────────────────┤
 │ **底层接管层级**     │ 应用层代理 (注册表写入 HTTP 代理)│ 网络层/传输层接管 (Wintun.dll 虚拟网卡)│
 │ **本地代理端口**     │ 127.0.0.1:10809 (HTTP/SOCKS) │ 无需端口，直接接管整机虚拟网络数据包   │
 │ **浏览器支持度**     │ 🟢 完美接管 Chrome/Edge/Firefox | 🟢 完美接管整机所有浏览器与前端应用   │
 │ **桌面软件接管**     │ 🟡 仅接管遵循 Windows 代理规范的软件| 🟢 强行穿透所有软件（包括 Telegram/Discord）│
 │ **联机游戏加速**     │ 🔴 完全无法接管游戏 UDP 流量   │ 🟢 完美加速 Steam、外服游戏与语音开黑  │
 │ **开发终端 CLI**     │ 🔴 CMD/PowerShell 必须手动设代理| 🟢 命令行、Git、Docker、WSL 全局无感透明代理│
 │ **系统权限要求**     │ 普通用户权限即可直接运行     │ **必须强制以管理员身份运行客户端**     │
 └──────────────────────┴──────────────────────────────┴───────────────────────────────────────┘
```

### 1. 如何正确开启【系统代理】？
- 在 Windows 任务栏右下角小托盘中，找到蓝色 V 字图标；
- 鼠标右键点击图标 ──► 选择【自动配置系统代理】；
- 此时托盘中的 **V 字图标会从蓝色变为鲜艳的红色**，代表系统代理已正式开启，浏览器打开 `google.com` 即可秒开！

### 2. 如何正确开启【TUN 模式】（游戏/开发神器）？
- 确认当前 v2rayN 是通过【管理员权限】启动的；
- 打开 v2rayN 主界面，在最下方找到并勾选 **【启用 TUN 模式】**（部分版本位于【设置】──►【TUN 模式设置】）；
- 首次开启时，客户端会自动调用 `wintun.dll` 在设备管理器中生成一张虚拟网卡，瞬间接管整台电脑的所有 TCP/UDP 流量！

## 七、电脑重启没网/关掉客户端没网？——彻底清除系统代理残留

这是 Windows 平台使用代理软件最常见、最容易让新手惊慌失措的“世纪难题”：

```text
 ⚠️ 【故障现象描述】：
 关掉 v2rayN 或者电脑异常关机重启后，发现电脑全线断网！微信打不开，任何网页都提示“代理服务器连接失败”。
 
 物理诱因揭秘：
 - v2rayN 开启系统代理时，会在 Windows 注册表中把系统代理服务器指向 `127.0.0.1:10809`；
 - 当程序被任务管理器直接强杀、或意外断电关机时，v2rayN 来不及执行“注销代理”动作；
 - 导致系统代理地址被死锁在注册表中，而此时后台并没有 10809 端口在监听，整台电脑变成网络盲人！
 
 🟢 20 秒极速恢复标准解法：
 1. 【方法一（最快）】：重新打开 v2rayN 客户端，右键右下角托盘图标，点击【清除系统代理】，托盘图标变蓝后，再正常点击【退出】即可优雅清除；
 2. 【方法二（手动 Windows 设置）】：
    - 按下快捷键 `Win + I` 打开 Windows 设置；
    - 点击【网络和 Internet】──► 选择【代理】；
    - 在手动设置代理区域，将【使用代理服务器】的开关切实【关闭】，点击保存，网络瞬间复原！
```

```text

 ❌ 误区 5：关掉 v2rayN 后电脑打不开网页是因为电脑中了勒索病毒。(错！纯粹是注册表系统代理残留，一键清除即可秒级恢复)
 ❌ 误区 6：去网上找不知名的“v2rayN 一键提速注册表补丁”导入电脑。(错！极具后门木马风险且根本无法提升物理带宽)

 ❌ 误区 8：只要订阅了优质专线机场，本地电脑就算时间差了 10 分钟也照样能连。(错！TLS 握手要求系统时钟偏差不得超过 60 秒)
 ❌ 误区 9：开启了系统代理后，CMD 终端和 Git 就自动全部翻墙了。(错！CLI 默认不认 Windows 系统代理，需开 TUN 或设终端代理)
```

## 十、常见问题解答 (FAQ)

### Q1：为什么双击 v2rayN.exe 没有任何反应，或者提示找不到 .NET？
**答**：v2rayN 6.x/7.x 基于微软最新平台构建，系统必须预先安装 **Microsoft .NET Desktop Runtime 8.0 (x64)**。前往微软官网下载安装该桌面运行时补丁后即可正常启动。

### Q2：下载后解压打开提示“找不到核心组件”或“Core 无法启动”怎么回事？
**答**：你误下载了不带内核的纯净版（`v2rayN-windows-64.zip`）。请返回官方发布页重新下载带核心的完整安装包 **`v2rayN-windows-64-With-Core.zip`**，重新解压到纯英文路径即可。

### Q3：为什么 Tcping 延迟只有几十毫秒，但网页依然打不开？
**答**：Tcping 仅仅测试你的电脑到中转机房的物理端口连通性，即便节点服务端断网或出口封锁，Tcping 也会显示绿字！按下键盘快捷键 **`Ctrl + R` 测试真连接延迟 (True Delay)**，只有真延迟有数值的节点才是真正可用节点。

### Q4：为什么关闭 v2rayN 之后，整台电脑网页全打不开了，QQ 微信也断网？
**答**：属于经典的**系统代理残留**！重新打开 v2rayN，在右下角托盘图标右键点击【清除系统代理】即可；或在 Windows 系统设置中搜索【代理】，手动将“使用代理服务器”开关关闭。

### Q5：为什么 Chrome 浏览器能翻墙，但下载的独立软件或 Git 命令行不走代理？
**答**：普通【系统代理】仅接管标准的网页流量；很多独立软件与命令行工具不读取 Windows 注册表代理。**开启 v2rayN 的【TUN 模式】**（需管理员权限运行），即可通过虚拟网卡接管整机所有网络流量。

### Q6：打外服游戏或连 Steam 语音，应该选系统代理还是 TUN 模式？
**答**：**必须选择 TUN 模式！** 游戏数据包和语音通话绝大部分基于无连接的 UDP 协议，系统代理完全无法转发 UDP；TUN 模式通过驱动级虚拟网卡能够无缝代理游戏 UDP 流量。

### Q7：开启代理后，为什么国内的微信和网银非常卡，甚至提示异地登录风险？
**答**：检查客户端主界面下方的【路由】选项，确保选择为 **【绕过大陆 (bypass-mainland)】**。若误选为【全局 (global)】，国内所有流量都会绕道欧美服务器，导致严重的卡顿并触发银行反欺诈拦截。

### Q8：遇到 v2rayN 节点全部报 Timeout，第一步该查什么？
**答**：第一步**核对 Windows 系统时间**！按下 `Win + I` 打开日期和时间设置，点击【立即同步】。TLS/VLESS Reality 加密握手严苛要求本地与国际标准时间误差不能超过 60 秒，时间对不准会导致所有节点全红超时。
