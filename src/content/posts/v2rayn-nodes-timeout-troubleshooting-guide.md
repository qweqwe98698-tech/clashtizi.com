## 四、Xray-core / sing-box 内核崩溃与杀毒软件拦截排查

有时候全部超时，纯粹是因为底层负责干活的 Core 引擎根本没有被启动：

```text
 1. 【排查任务管理器内核进程】：
    - 按快捷键 `Ctrl + Shift + Esc` 打开 Windows 任务管理器；
    - 检查“后台进程”中是否有 `xray.exe` 或 `sing-box.exe`；
    - 若只有 `v2rayN.exe` 而没有 Core 进程，说明内核启动失败或已被闪退强杀！

 2. 【杀毒软件误杀防护（火绒 / 360 / Windows Defender）】：
    - 国内外许多杀毒软件会将编译版 Xray-core 误报为“RiskWare”或“代理木马”；
    - 杀软会在你双击打开 v2rayN 的瞬间，静默将 `xray.exe` 拖入隔离区并删除！
    - 应对：打开杀毒软件的【隔离区 / 拦截日志】，找到被拦截的 `xray.exe` 选择【恢复并添加到信任白名单】；
    - 同时，在杀毒软件设置中将整个 `D:\v2rayN\` 文件夹整体添加为信任目录。
```

## 五、本地端口占用排查：10808 / 10809 端口被死锁冲突

v2rayN 默认使用 `10808` (SOCKS) 和 `10809` (HTTP) 本地监听端口：

```text
 1. 【端口冲突的表现】：
    - 主界面左下角控制台报错：“Failed to start core... Only one usage of each socket address is normally permitted”；
    - 说明 10808 端口已经被另一个正在运行的软件占满了，内核无法绑定端口。

 2. 【快速定位与解除占用】：
    - 按快捷键 `Win + R` 输入 `cmd` 打开命令行；
    - 输入命令并回车：`netstat -ano | findstr 10808`
    - 查看最后一列显示的数字 PID（进程编号）；
    - 若发现是之前的某个僵死 v2rayN 或 Clash 残留，在任务管理器中强制结束该 PID 即可；
    - 或者在 v2rayN【设置】──►【参数设置】──►【Core 基础设置】中，将本地监听端口修改为 `20808` 和 `20809`。
```

## 九、常见问题解答 (FAQ)

### Q1：为什么昨天用得好好的，今天一开机 v2rayN 节点全部报 -1 超时？
**答**：**80% 是因为电脑系统时间不准！** 许多主板纽扣电池老化会导致关机后时钟落后几分钟；TLS 加密协议要求误差在 60 秒以内。按下 `Win + I` 打开时间设置点击【立即同步】即可秒级复活。

### Q2：为什么「测试服务延迟 (Tcping)」全绿，但「真连接延迟 (True Delay)」全是全红 -1？
**答**：Tcping 仅仅代表你的电脑能连上国内的中转机房服务器；只要国内服务器开着机就会显示绿字！而真连接延迟才是真正打通到海外 Google 的端到端测试；只有真延迟显示数字的节点才能真正上网。

### Q3：按快捷键 Ctrl+R 测速时，瞬间全红并提示“启动服务失败”是怎么回事？
**答**：说明底层的 `xray.exe` 内核被杀毒软件（如火绒、360 或 Windows Defender）拦截或删除了！打开杀毒软件的隔离区将核心文件恢复，并将 v2rayN 目录加入信任白名单。

### Q4：提示“Only one usage of each socket address is normally permitted”是什么意思？
**答**：这是经典的本地端口占用冲突报错！说明本地默认的 `10808` 或 `10809` 端口被其他代理软件抢先占用了；在任务管理器中彻底清理后台残留进程，或在参数设置中修改端口即可。

### Q5：手机连同一个 Wi-Fi 翻墙很正常，为什么电脑上的 v2rayN 全红连不上？
**答**：证明机场节点和网络本身完全通畅，瓶颈 100% 在这台电脑上！重点排查：①电脑系统时钟是否精准；②电脑杀毒软件是否拦截了 `xray.exe`；③电脑本地端口是否被占用。

### Q6：连家里 Wi-Fi 节点全部 Timeout，但连手机 5G 热点就瞬间变绿是为什么？
**答**：这证明节点正常，问题出在家庭网络上！通常是光猫或宽带运营商对该代理端口进行了临时性丢包干扰，或者路由器 DNS 遭到了污染；重启光猫更换外网 IP 即可恢复。

### Q7：v2rayN 怎么批量快速清理所有报 Timeout 的废弃节点？
**答**：按 `Ctrl + A` 全选当前分组所有节点 ──► 按 `Ctrl + R` 测出真延迟 ──► 点击表头的【真连接延迟】列进行排序，所有 `-1` 的红节点会自动集中到底部 ──► 框选它们按下键盘 `Delete` 键即可一键清空。

### Q8：遇到节点全部超时，最忌讳的操作是什么？
**答**：最忌讳“不看报错病急乱投医狂点测速几十次，甚至去重装系统”。按照“校准系统时间 ──► 检查任务管理器内核 ──► 连手机 5G 热点对照”三步法，95% 的全红故障都能在 2 分钟内精准修复。
