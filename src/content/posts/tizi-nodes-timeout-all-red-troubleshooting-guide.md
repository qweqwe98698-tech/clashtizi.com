> **【💡 30 秒极速直接答案：节点全部 Timeout 核心定性与四大排障原则】**
> - **第一核心定性**：**“节点列表全红报 Timeout 或 -1，80% 的情况绝非机场跑路，而是本地系统时钟误差、客户端测速目标 URL 阻断、本地杀毒软件强杀内核、或本地 Wi-Fi 路由阻断！”**；
> - **六类典型“全部超时”极速对号入座**：
>   1. **所有节点测速全红报 Timeout，但浏览器打开外网其实能用** ──► 属于**测速目标 URL (如 google 204) 被墙或失效** ──► 换测速网址即可，红字不影响实际使用；
>   2. **换了手机 5G 热点全变绿，连家里 Wi-Fi 必全红** ──► 属于**本地光猫/路由器 DNS 拦截或运营商 QoS** ──► 修改本地公共 DNS（如 223.5.5.5）或重启光猫；
>   3. **手机上测速全绿正常，同网络下电脑全部报 Timeout** ──► 属于**电脑系统时间误差 > 60 秒**（触发 TLS 防重放自毁）或**杀毒软件隔离了内核** ──► 同步 Windows 时间并加白名单；
>   4. **单地区（如所有香港）全红，其他日本/美国正常** ──► 属于**该地区公网中继海缆单点故障** ──► 切换到日本或新加坡节点过渡；
>   5. **昨天飞快今天突然全红，且订阅更新报 401/403** ──► 属于**机场套餐欠费到期或流量用尽** ──► 登录机场后台续费；
>   6. **一开启 TUN 模式节点瞬间全部报超时** ──► 属于**虚拟网卡未获管理员权限导致网络回环死锁** ──► 以管理员身份运行客户端。

| **F：一开启 TUN 模式，所有节点瞬间全红** | 虚拟网卡驱动层 | 未以管理员运行，虚拟网卡劫持了回环流量造成死锁 | 退出软件，右键以管理员身份重新运行客户端 |

## 四、技术解密：为什么 Ping 显示 20ms 绿字，实际还是用不了？

很多用户常问：“我的节点列表里 ping 明明显示 20ms 绿字，为什么连上去死活打不开网页？”

```text
 ⚠️ 【Ping (ICMP/Tcping) 与 真实连接延迟 (URL Test) 的本质区别】：
 - 【ICMP Ping / Tcping 假绿字】：
   * 它仅仅测试你的电脑到国内 BGP 中转机房的物理握手（耗时通常只有 20~40ms）；
   * 它完全不验证海外落地机房是否通畅，哪怕你的机场账号欠费停机，Tcping 也一样显示 20ms 绿字！
 - 【真实连接延迟 (URL Test / True Delay)】：
   * 客户端实际通过该节点发起一次 HTTP GET 请求到全球权威测试源（如 Cloudflare 或 Google）；
   * 只有当数据包真正穿透跨境海缆、到达海外落地机房并成功返回时，才算测速成功；
 - 【结论】：千万不要看客户端里的 Ping！必须以 **【URL Test / 真连接延迟】** 的数值为准！
```

## 五、5G 热点交叉对照法：秒级锁定是本地宽带还是机场问题

排查节点全红最科学、最快速的排障工具就是你手边的手机：

```text
 1. 【执行 5G 热点对照操作】：
    - 断开电脑正在连接的家庭 Wi-Fi；
    - 打开手机【个人热点】，电脑连接手机 5G 热点；
    - 在客户端中全选节点重新发起一次真延迟测试。

 2. 【秒级定性结论】：
    - 【结果 A：连 5G 热点后瞬间全绿】：
      * 100% 证明你的电脑软件、系统时钟和机场节点完全没问题！
      * 瓶颈纯粹出在家里的路由器或光猫上（光猫 DNS 污染、路由器防火墙拦截了特定端口）；
      * 解决动作：重启光猫，将电脑本地网卡的 DNS 手动修改为公共 DNS（如 `223.5.5.5`）。
    - 【结果 B：连 5G 热点后依然 100% 全红】：
      * 说明故障与家庭宽带无关，问题集中在“电脑系统时钟偏差”、“杀软拦截内核”或“机场全线节点故障”。
```

## 六、本地 Core 核心闪退排查：被杀毒软件静默误杀

有时你看到客户端界面还在，但测速全部报连接失败：

```text
 1. 【如何检查内核是否存活？】：
    - 按下 `Ctrl + Shift + Esc` 打开 Windows 任务管理器；
    - 检查后台进程：
      * Clash Verge Rev 用户：确认是否存在 `verge-mihomo.exe`；
      * v2rayN 用户：确认是否存在 `xray.exe`；
    - 若找不到对应核心，100% 说明核心程序已被杀毒软件判定为高危并强行隔离！

 2. 【彻底解决办法】：
    - 打开 Windows Defender 或火绒 / 360 的【拦截日志】与【隔离区】；
    - 找到被隔离的核心文件，点击【信任并恢复】；
    - 在杀毒软件的【排除项】中，将客户端所在的解压文件夹整体加入白名单。
```

## 九、常见问题解答 (FAQ)

### Q1：为什么节点列表全是红色的 Timeout，但浏览器打开 YouTube 却能正常播放？
**答**：这是极为典型的**测速机制误报**！客户端测速是向特定网址（如 `generate_204`）发包；若该测速网址受到临时干扰或被屏蔽，测试就会显示全红，但节点本身的海外网络链路完全正常。在设置中更换测速 URL 即可，红字完全不影响实际使用。

### Q2：手机连接同一 Wi-Fi 节点测速全绿，但 Windows 电脑上全部显示 Timeout 怎么回事？
**答**：**90% 是因为电脑的 Windows 系统时间不准！** 现代加密协议严禁本地时间与国际标准时间偏差超过 60 秒；在 Windows【日期和时间】设置中点击【立即同步】校准时间，重新测速瞬间全绿。

### Q3：为什么连家里 Wi-Fi 测速全部超时，切换到手机 5G 热点瞬间全绿？
**答**：说明机场节点和电脑均完全正常，问题 100% 在家庭路由器或本地宽带上！常见原因包括：光猫下发的运营商 DNS 遭到投毒、或路由器开启了防翻墙保护；在电脑无线网卡属性中将 DNS 手动修改为 `223.5.5.5`，或重启光猫即可解决。

### Q4：节点全部报 -1 或者提示“Connect Error”怎么办？
**答**：说明客户端向本地核心发起的请求被拒绝，底层 Core（如 `mihomo.exe` 或 `xray.exe`）已经闪退或被杀毒软件误杀！打开任务管理器确认核心进程是否存在，将客户端解压目录整体添加进杀软的信任白名单。

### Q5：为什么只有部分香港节点全红，日本和美国节点都是绿色？
**答**：属于局部的中继海缆故障或机房单点维护。公网国际出口时常发生波动，此时无需惊慌，鼠标切换至延迟正常的日本、新加坡或美国专线节点继续使用即可。

### Q6：昨天用得好好的，今天突然所有节点全部超时，订阅更新也失败怎么解决？
**答**：通常是因为：①机场套餐到期欠费；②当月流量配额耗尽；③机场更换了全套节点域名或遭受 DDoS 攻击。登录机场官网后台查看最新公告与流量余额即可。

### Q7：什么是 Tcping 假绿字？为什么显示 20ms 依然上不了网？
**答**：Tcping 仅仅测试你的设备到国内中转机房的物理网络，即便服务器海外出口彻底断网或账号停机，Tcping 依然会显示 20ms 绿字；必须使用真实 HTTP 请求的【URL Test / 真连接延迟】测试才具备参考价值。

### Q8：遇到节点全部超时，最忌讳的操作是什么？
**答**：最忌讳“盲目删除订阅、清空配置或重装电脑系统”。严格遵循“同步系统时钟 ──► 5G 热点交叉对比 ──► 检查核心进程存活 ──► 检查账号余额”四步排查法，99% 的超时难题都能在 3 分钟内彻底解决。
