| :--- | :--- | :--- | :--- |
| **1. 路由器 IPv6 流量泄漏** | 客户端未接管 IPv6，流量裸连直连出境被墙 | 5G 流量能用，一连 Wi-Fi 就断网 | **登录路由器后台关闭 IPv6 开关** |
| **2. 宽带运营商 DNS 劫持** | 本地宽带对海外域名实施投毒与篡改 | 提示 `DNS_PROBE_FINISHED_NXDOMAIN` | **配置 DoH + 修改路由器 DNS** |
| **3. 旁路由 / 软路由网关死锁**| 设备网关指向旁路由但旁路由核心未运行 | Wi-Fi 连上后所有网络全瘫痪 | **排查局域网 DHCP 网关与 DNS 设置** |
| **4. 无线网卡 MTU 分片丢包**| Wi-Fi 信号抖动叠加 1500 MTU 超载拆包 | 网页一直转圈，图片加载不全 | **客户端 TUN 设置调整 MTU 为 1400** |
| **5. 路由器 AP 隔离机制** | 路由器开启了 AP 隔离，拦截局域网端口转发 | 多设备共享代理失败，提示拒绝连接 | **路由器无线设置中关闭【AP 隔离】** |
| **6. 代理模式误选为 Direct** | 客户端运行模式被误点为直连模式 | 国内正常，国外全部无法连接 | **将运行模式切换回【Rule 规则模式】** |

## 二、终极深度排查六步法（从路由器后台到无线网卡全流程排查）

按以下标准 6 步流程逐一排查，可彻底修复 100% 的“连 Wi-Fi 无法访问国外网站”问题：

### 第一步：登录路由器后台彻底关闭 IPv6（首选必杀大招）
- **故障根因**：国内三大运营商（电信/联通/移动）在家庭宽带中全面推广 IPv6。当海外网站支持 IPv6 时，操作系统会遵循 RFC 规范优先发起 IPv6 握手。由于绝大多数代理节点不支持 IPv6 转发，流量直接裸连出境被防火墙切断；
- **操作步骤**：
  1. 查看路由器底部标签，获取后台管理地址（通常为 `192.168.1.1`、`192.168.31.1` 或 `192.168.0.1`）；
  2. 打开浏览器输入管理 IP，输入管理员密码登录；
  3. 点击进入【网络设置】或【高级设置】──► 找到 **【IPv6 设置】**；
  4. 将 **【IPv6 开关】彻底关闭 (Disabled)**，点击保存；
  5. 重启路由器与手机/电脑，重新连接 Wi-Fi 即可瞬间恢复！

### 第二步：修改路由器 WAN/LAN 口与本机无线网卡 DNS
- **操作步骤**：
  1. 在路由器【LAN 局域网设置】中，将 DHCP 分发的 DNS 地址手动指定为：
     * 首选 DNS：**`223.5.5.5`**（阿里公共 DNS）
     * 备选 DNS：**`119.29.29.29`**（腾讯公共 DNS）
  2. 打开电脑【网络和 Internet】──►【Wi-Fi 属性】──► 将 IPv4 DNS 同样设为手动公共 DNS；
  3. 在客户端中开启 **加密 DoH**（如 `https://1.1.1.1/dns-query`），彻底消灭运营商 DNS 劫持。

### 第三步：客户端开启 TUN 虚拟网卡与【允许局域网连接】
- 打开代理客户端（**[Clash Verge Rev](/clash-verge-rev/)** / **[v2rayN](/v2rayn/)**）；
- 在设置中开启 **【TUN 模式 (TUN Mode)】**，强制接管 Wi-Fi 无线网卡的所有 TCP/UDP 流量；
- 若需要给局域网内的其他设备（如 Switch、电视盒子、手机）共享代理，勾选 **【允许局域网连接 (Allow LAN)】**。

### 第四步：排查局域网是否有旁路由/软路由 DHCP 冲突
- 如果你家里部署了 OpenWrt 软路由或旁路由：
  * 确保主路由的 DHCP 网关与 DNS 设置**没有形成死循环环路**；
  * 若旁路由未开启开机自启代理，会导致所有连接 Wi-Fi 的设备默认网关失效断网；
  * 测试时可先将手机/电脑的网关手动改回主路由 IP（如 `192.168.1.1`）以隔离故障。

### 第五步：调整无线网卡 MTU 大小并重置 Wi-Fi 网络适配器
- 无线 Wi-Fi 信号在经过空间衰减与代理协议二次封装后，默认 1500 MTU 极易出现分片丢包；
- 在客户端 TUN 设置中，将 **MTU 调整为 `1400` 或 `1280`**；
- 在 Windows 设置中点击【网络重置】，重新初始化无线网卡驱动。

### 第六步：选用具备三网 BGP 智能接入的优质专线
- 家用 Wi-Fi（尤其是移动宽带和冷门二级宽带）公网国际出口质量极差，晚高峰海缆拥堵严重；

## 三、家庭网络拓扑（光猫桥接 vs 光猫拨号）专属排障

```text
 1. 【模式 A：光猫桥接 + 路由器拨号 (推荐最佳方案)】：
    - 光猫仅负责光电信号转换，路由器拥有独立公网 IP 与完整的 NAT/防火墙控制权；
    - 只需在路由器后台关闭 IPv6 并配置 DNS，局域网所有设备即可完美科学上网。

 2. 【模式 B：光猫拨号 + 路由器动态 IP (二级路由模式)】：
    - 很多小白在路由器上关闭了 IPv6，但上一级的“运营商光猫”依然开启了 IPv6 并下发了无状态前缀；
    - 解法：必须登录光猫超级管理员后台（或联系装维师傅）在光猫中同步关闭 IPv6！
```

## 六、常见高频问题解答 (FAQ)

### Q1：为什么用手机 5G 移动网络能正常上外网，一连家里 Wi-Fi 就断网？
**答**：**最常见的原因是家用路由器开启了 IPv6 导致流量泄漏！** 手机连 Wi-Fi 时系统优先使用未被代理客户端接管的 IPv6 直连出境被 GFW 拦截。登录路由器后台将【IPv6】彻底关闭即可秒级解决。

### Q2：如何登录路由器后台关闭 IPv6？
**答**：查看路由器底部标签获取后台管理地址（如 `192.168.1.1` 或 `192.168.31.1`）；手机/电脑浏览器打开该地址输入密码登录 ──► 进入【网络设置】──► 找到【IPv6 设置】──► 将其切换为【关闭】并保存重启。

### Q3：如果在路由器上关了 IPv6 依然打不开外网怎么办？
**答**：如果你的光猫处于“光猫拨号”模式，光猫自身可能依然在向局域网广播 IPv6 地址；需要登录光猫后台将光猫的 IPv6 同步关闭，或者联系装维师傅将光猫改为“桥接模式”，由路由器独立拨号。

### Q4：为什么修改路由器 DNS 能够改善 Wi-Fi 访问体验？
**答**：因为宽带运营商默认下发的 DNS 存在严重的明文劫持与域名投毒；将路由器 DNS 手动改为 **`223.5.5.5`（阿里）** 或 **`119.29.29.29`（腾讯）**，可彻底避免国内 CDN 节点解析错误。

### Q5：什么是 AP 隔离？为什么它会影响局域网共享代理？
**答**：AP 隔离是路由器为了安全禁止连接同一个 Wi-Fi 的设备互相通信。如果你想通过电脑给手机或电视盒子共享代理，必须在路由器无线高级设置中将【AP 隔离】关闭。

### Q6：为什么连 Wi-Fi 打开 Google 提示 `ERR_CONNECTION_REFUSED`？
**答**：说明浏览器尝试连接的代理端口（如 7890）未被客户端监听。在代理客户端中点击【重启内核】，并检查是否安装了冲突的浏览器代理插件。

### Q7：什么是 TUN 模式？Wi-Fi 环境下需要开吗？
**答**：TUN 模式是通过创建虚拟网卡接管全系统所有流量。在 Wi-Fi 环境下强烈建议开启 TUN 模式，它能强制接管无线网卡的所有流量，彻底杜绝 IPv6 泄漏与 DNS 污染。

### Q8：长期使用，如何确保家庭 Wi-Fi 环境下外网稳定秒开？
