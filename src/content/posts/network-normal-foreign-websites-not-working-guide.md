## 二、终极深度排查六步法（从应用层到网络栈深度修复）

按以下标准 6 步流程逐一排查，可彻底修复 100% 的“网络正常但国外网站打不开”故障：

### 第一步：禁用浏览器的 Experimental QUIC 协议（首选大杀器）
- **故障原理**：现代浏览器默认尝试使用基于 UDP 的 QUIC (HTTP/3) 协议连接 Google、YouTube；而中国大陆运营商对跨境 UDP 流量实施极高等级的丢包和 QoS 限制，导致 TCP 无法降级一直处于超时状态；
- **操作步骤**：
  1. 在 Google Chrome 或 Microsoft Edge 地址栏输入：`chrome://flags`（Edge 输入 `edge://flags`）并回车；
  2. 在顶部搜索框输入：`quic`；
  3. 找到 **`Experimental QUIC protocol`**，将其右侧的下拉菜单改为 **【Disabled】**；
  4. 点击右下角弹出的 **【Relaunch (重启浏览器)】** 按钮。

### 第二步：刷新本地 DNS 缓存并配置公共 DoH
- **操作步骤**：
  1. 按下快捷键 **`Win + R`** 打开运行窗口，输入 `cmd` 并按回车；
  2. 在黑底命令行窗口中输入以下命令并回车：
     ```cmd
     ipconfig /flushdns
     ```
  3. 提示“已成功刷新 DNS 解析缓存”；
  4. 在代理客户端（如 **[Clash Verge Rev](/clash-verge-rev/)**）中配置远程 DNS 为 `https://1.1.1.1/dns-query`，彻底杜绝明文 DNS 投毒。

### 第三步：客户端将 DNS 模式切换为 Fake-IP
- 在 Clash 设置中，将 DNS 运行模式由 `redir-host` 切换为 **`fake-ip`**；
- **原理**：Fake-IP 模式下，客户端会向浏览器直接返回一个保留网段的虚拟 IP（如 `198.18.0.x`），浏览器无需等待真实的 DNS 解析即可发起 TCP 连接，将域名解析完全交由海外远端代理服务器处理，实现 0 污染秒级解析。

### 第四步：检查 Windows 代理端口注册表是否正确接管
- 打开 Windows【设置】──►【网络和 Internet】──►【代理】；
- 检查【使用代理服务器】是否为开启状态，【代理 IP 和端口】是否正确指向客户端监听端口（如 `127.0.0.1:7897` 或 `127.0.0.1:10808`）；
- 若未开启，返回客户端重新打开【系统代理 (System Proxy)】开关。

### 第五步：管理员重置 Winsock 底层网络栈
- 当其他软件篡改了 Windows LSP 网络分层服务提供程序时；
- 鼠标右键点击 Windows 开始菜单 ──► 选择 **【终端管理员 (或命令提示符管理员)】**；
- 依次输入以下两条命令并回车：
  ```cmd
  netsh winsock reset
  netsh int ip reset
  ```
- 重启电脑，底层网络协议栈将彻底恢复纯净初始状态。

### 第六步：排查节点晚高峰丢包并切换优质专线
- 运行客户端批量测速；若节点测速显示 `Timeout` 或真实单线程速度不足 100Kbps，说明当前节点已被防火墙拉黑或严重超售；

## 六、常见高频问题解答 (FAQ)

### Q1：为什么国内网站秒开、测速满载，但所有国外网页一直连接超时？
**答**：**最常见的原因是浏览器尝试使用 QUIC (UDP) 协议连接海外服务器，但跨境 UDP 被运营商防火墙丢弃！** 在 Chrome/Edge 地址栏输入 `chrome://flags` 将 **Experimental QUIC protocol 设为 Disabled** 即可秒级解决。

### Q2：为什么刷新 DNS 缓存能够解决国外网站打不开？
**答**：因为当你未开代理访问外网时，本地宽带 DNS 会将污染后的虚假 IP 缓存到 Windows 系统中；运行 **`ipconfig /flushdns`** 可以强制清空旧的错误缓存，让系统重新获取代理下发的纯净 IP。

### Q3：什么是 Fake-IP 模式？为什么它能解决 DNS 污染？
**答**：Fake-IP 模式是客户端直接返回一个保留网段的虚拟 IP（如 `198.18.0.1`），避免向本地运营商发起任何真实的 DNS 查询；真实的域名解析会在海外代理服务器端完成，彻底消除 DNS 污染与解析延迟。

### Q4：为什么关闭代理软件后，电脑连国内网站也打不开了？
**答**：这是系统代理端口未自动释放导致的。打开 Windows【设置】──►【网络和 Internet】──►【代理】──► 将【手动设置代理 / 使用代理服务器】开关**手动关闭**即可恢复上网。

### Q5：为什么浏览器能打开 Google，但 Git 命令行拉取 GitHub 一直超时？
**答**：因为命令行终端默认不走 Windows 系统代理；在代理客户端中开启 **【TUN 模式 (TUN Mode)】** 虚拟网卡，即可实现全系统所有软件的透明代理加速。

### Q6：Chrome 报错 `ERR_CONNECTION_REFUSED` 怎么修复？
**答**：说明浏览器找不到客户端代理端口。在客户端中点击【重启内核】，并检查浏览器是否安装了 SwitchyOmega 等第三方代理扩展，将其暂时禁用。

### Q7：什么是 Winsock 重置？什么时候需要执行？
**答**：Winsock 是 Windows 系统负责网络通信的核心 API；当系统被其他网络软件搞乱导致代理无法正常转发流量时，以管理员身份运行 **`netsh winsock reset`** 重启电脑可彻底修复网络栈。

### Q8：长期使用，如何确保海外网络稳定丝滑不超时？
**答**：参考站内 **[2026 翻墙机场权威排行榜](/recommend/airport/)** 挑选拥有千兆 BGP 入口与 IPLC 物理专线的正规大厂，配合规则分流与 Fake-IP 模式，开机即用，告别频繁超时的烦恼。
