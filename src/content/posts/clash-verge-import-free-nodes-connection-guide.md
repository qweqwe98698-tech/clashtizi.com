- 若你从网上获取的是以 `vmess://`、`vless://` 开头的代码或 Base64 文本；

- 打开 **[Clash Verge Rev](/clash-verge-rev/)** 客户端；
- 点击左侧导航栏 **【订阅 (Profiles)】**；

### 步骤 4：代理组选节点与系统代理开启

## 六、常见高频问题解答 (FAQ)

### Q1：Clash Verge 导入免费订阅最关键的一步是什么？
**答**：**下载后必须“鼠标左键单击配置卡片”使其边框高亮变色！** 很多小白下载完配置后没有点击选中激活，内核依然处于空配置状态，导致无法上网。

### Q2：为什么免费节点订阅导入时提示 Download Configuration Failed？
**答**：本地宽带无法直连订阅分发服务器；在 Clash Verge 左侧【设置】中**开启已有的备用代理，勾选【使用系统代理更新订阅】**，然后再次点击下载即可成功。

### Q3：为什么节点测速全部显示 Timeout 超时？
**答**：①检查 Windows 系统时间是否比标准北京时间快/慢了 60 秒以上，SSL 证书失效会导致全红；②免费节点生命周期已过，在配置卡片右键点击【更新】重新拉取最新节点。

### Q4：为什么开启 Clash Verge 后国内微信和百度打不开？
**答**：检查主界面顶部的运行模式是否误选为了【Global (全局模式)】；**务必将其切换为【Rule (规则模式)】**，规则模式下国内流量走本地直连，国外走代理。

### Q5：Clash Verge 怎么开启 TUN 模式接管游戏和 Telegram？
**答**：在左侧【设置】中，点击【Service Mode (服务模式)】安装系统驱动；然后打开 **【TUN Mode (TUN 模式)】** 开关，即可实现全系统所有软件与外服游戏无感透明代理。

### Q6：关闭 Clash Verge 软件后电脑无法上网怎么修复？
**答**：打开 Windows【设置】──►【网络和 Internet】──►【代理】──► 将【手动设置代理 / 使用代理服务器】开关**手动关闭**即可恢复上网。

### Q7：什么是 Clash Verge 的 Mihomo (Meta) 内核？
**答**：Mihomo 是 Clash 开源社区最活跃的进阶内核，原生支持 VLESS Reality、Hysteria 2、TUIC 等最新高性能抗封锁协议，在 Clash Verge Rev 中默认推荐使用。
