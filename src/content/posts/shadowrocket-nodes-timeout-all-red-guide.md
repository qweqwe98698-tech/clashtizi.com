> - **第一前提确认**：**本指南仅适用于“Shadowrocket 列表中已经出现节点，但点击测速全部标红 Timeout 或无法连接”的情形**！若列表为空，请先看 [订阅导入与节点不显示排查](/shadowrocket/subscription/)；
> - **第一核心定性**：**“所有地区节点瞬间集体变红”绝不是 20 个不同国家的服务器同时被炸毁，而是 100% 触发了本地“公共阻断变量”！** 90% 的诱因集中在：**手机系统时间误差 > 60 秒触发 TLS 证书校验死锁**、**家庭 Wi-Fi 路由器的 DNS 污染**或**账号流量用尽**；
> - **四种 Timeout 现象极速归因与分诊**：
>   1. **仅有 1~2 个节点 Timeout，其他节点显示绿色毫秒** ──► 属于**该特定服务器单机维护**，直接切换其他可用节点，切勿改动手机网络；
>   2. **某一国家（如全部日本节点）全红，其他国家正常** ──► 属于**该区域跨境海缆中转抖动**，临时改用香港或新加坡节点；
>   3. **Wi-Fi 下全红 Timeout，切换手机 5G 流量瞬间全部变绿** ──► 属于**家庭路由器 DNS 污染或光猫硬件级拦截**，去手机设置修改 Wi-Fi DNS 为 `223.5.5.5`；
>   4. **Wi-Fi 与 5G 流量下全部都死锁 Timeout** ──► 属于**系统时钟偏差导致 TLS 握手失败**或**后台多 VPN 扩展冲突**，校准北京时间并重启手机。

## 一、故障范围分类与第一优先级排查对照表

遇到节点测速异常，首先按受影响的范围进行定性：

| 故障现象分类 | 核心制约层级 | 最核心真实诱发诱因 | 第一步标准应对动作 |
| :--- | :--- | :--- | :--- |
| **A：只有一个特定节点标红 Timeout** | 远端单机服务器层 | 该机房单机硬件维护、端口被封或负载满载 | 切换到同一订阅下的其他绿色节点，无需改设置 |
| **B：同地区节点（如所有日本）全红** | 区域中转线路层 | 机场连接该地区的入口中转机房突发网络抖动 | 临时改选香港、新加坡或美国节点过渡使用 |
| **C：所有国家所有节点全部标红超时** | 本地公共变量层 | iPhone 时间不准、家庭 Wi-Fi 拦截或流量耗尽 | 校准系统时间、切换 5G 热点、登录后台查余量 |
| **D：Wi-Fi 下全红，切 5G 流量全绿** | 本地 Wi-Fi 路由层 | 宽带运营商下发了虚假 DNS，或路由器防火墙拦截 | 修改 Wi-Fi DNS，或重启家庭光猫与路由器 |
| **E：5G 下全红，连 Wi-Fi 却正常** | 移动蜂窝网络层 | 运营商基站对境外特定加密端口进行了 QoS 压制 | 在手机蜂窝网络设置中重置接入点 APN |
| **F：测速标红，但点开网页依然能用** | 测试机制差异层 | 小火箭测速探针网址被阻断，而实际代理链路正常 | 忽略测速红字，以实际能否打开 Google 为准 |
| **G：测速显示绿字，但网页彻底打不开** | 规则与分流层 | 节点与握手正常，但分流规则误判或 DNS 死锁 | 将全局路由切为【代理 (Proxy)】做受控排除 |

## 四、最隐蔽全红元凶：系统时钟偏差导致 TLS 握手集体暴毙

现代翻墙协议（如 VLESS Reality、Shadowsocks-2022、Trojan、Hysteria 2）高度依赖安全的 TLS 加密握手：

```text
 1. 【TLS 证书时效与防重放攻击机制】：
    - 服务器下发的 SSL/TLS 证书具有精确到秒的有效期范围；
    - 更关键的是，新一代加密协议引入了“时间戳防重放校验”：只要客户端时间与服务器时间相差超过【60 秒~90 秒】，服务器会将其视作恶意重放攻击，在网络层直接无视并丢弃数据包！
    - 表现形式：手机发出的每一个握手包都被服务端静默丢弃，导致小火箭在等待超时后，所有节点瞬间集体标红 Timeout。

 2. 【一键校准 iPhone 系统时钟】：
    - 打开系统【设置】──► 进入【通用】──► 点击【日期与时间】；
    - 查看【自动设置】开关：若处于关闭状态，立即打开；
    - 若原本就是打开的，先关闭它，等待 5 秒，再重新打开（强制触发苹果 NTP 服务器时间同步）；
    - 重新进入 Shadowrocket 测速，全节点奇迹般瞬间恢复全绿！
```

## 五、深入认知：连通性测试 (Connectivity Test) 是不是 Ping？

```text
 ┌─────────────────────────────────────────────────────────────────────────────────────────────┐
 │                               【连通性测试底层技术机制深度澄清】                            │
 ├─────────────────────────────────────────────────────────────────────────────────────────────┤
 │ 很多用户以为点击小火箭测速就是电脑上的“Ping 服务器”：                                      │
 │                                                                                             │
 │ ❌ 常见认知错误：“节点延迟显示 25ms，说明 Ping 延迟极低，看 4K 视频一定最快。”             │
 │                                                                                             │
 │ 💡 真实物理真相：                                                                           │
 │ 1. 【它不是 ICMP Ping】：iOS 系统权限严密限制了普通应用发起原始 ICMP 数据包的能力；小火箭的测速│
 │    实际上是通过节点向指定的 HTTP/TCP 测试网址（如 Cloudflare 或 Google）发送握手探针；      │
 │ 2. 【探针受阻 ≠ 节点断网】：如果服务商配置的测试网址本身在当地被运营商干扰，就会显示标红 Timeout；│
 │    但此时只要节点本身的 TCP 隧道完好，你开启连接后依然能正常秒开 Google 和 YouTube！       │
 │ 3. 【毫秒数字与带宽无关】：25ms 只代表握手极快，若该节点仅有 5Mbps 廉价小水管，看视频依然会卡死。│
 └─────────────────────────────────────────────────────────────────────────────────────────────┘
```

## 六、多 VPN 冲突与 iOS Network Extension 扩展死锁排查

iOS 系统对后台网络代理有着极其严苛的沙盒保护机制：

```text
 1. 【多个网络扩展争抢系统通道】：
    - 若你的手机上同时安装并开启了其他代理或隐私软件（如 Quantumult X、Loon、Stash、企业 VPN、或某些杀毒安全卫士）；
    - iOS 的 Network Extension 框架只允许一个应用独占系统主虚拟通道。多软件争抢会导致路由表混乱，底层网络通道陷入死锁，从而导致所有节点无法发送握手包。

 2. 【飞行模式秒级重置大法】：
    - 滑出 iPhone 控制中心，点击【飞行模式】图标开启；
    - 等待 8~10 秒，让 iOS 系统彻底释放底层网络连接与套接字；
    - 关闭飞行模式，等待 5G/Wi-Fi 重新连通后，打开 Shadowrocket 重新连接。
```

```text
 1. 【流量用尽时的服务端表现】：
    - 当你在机场购买的当月流量配额彻底消耗至 0%，或者套餐订阅到期后；
    - 多数机场后端的 RADIUS/V2Ray 认证节点会在边缘层直接丢弃或拒绝你的连接请求；

 2. 【验证动作】：
    - 使用手机 Safari 浏览器（断开代理连接）访问机场官方网站；
    - 登录个人中心，检查【剩余流量】是否为 0GB，查看【到期时间】是否已经过期；
    - 若确实用尽，重置流量或续费套餐后，回到小火箭下拉刷新订阅即可恢复。
```

## 九、关于节点全红 Timeout 的 15 大核心认知误区

```text
 ❌ 误区 1：节点全部变红，就 100% 代表买的机场绝对跑路了，必须马上删订阅。(错！大半是本地系统时间或Wi-Fi问题)
 ❌ 误区 2：只要测速标红 Timeout，这个节点就绝对不可能打开任何网页。(错！测速探针网址被阻断不影响实际代理链路)
 ❌ 误区 3：节点全红时，疯狂快速连击刷新几百次能“冲破”网络阻断。(错！只会触发服务端的防刷拉黑机制导致封禁)
 ❌ 误区 4：为了解决节点超时，在设置里把 TLS 证书安全验证彻底关闭。(错！极具隐私泄露风险，且治标不治本)
 ❌ 误区 5：看到一个节点是 15ms，就断定它看 4K 视频的速度一定比 120ms 的节点快。(错！毫秒是延迟，视频看带宽)
 ❌ 误区 6：把小火箭卸载重新下载安装，就能自动修好所有节点全红的问题。(错！重新下载依然解决不了 Wi-Fi 污染或时间偏差)
 ❌ 误区 7：在家庭 Wi-Fi 连不上，手机开 5G 肯定也连不上，所以不用试了。(错！5G 热点交叉测试是最有效的排障手段)
 ❌ 误区 8：节点全红时，把订阅里的几十个节点参数全部手动改一遍。(错！破坏配置一致性，后续无法自动更新)
 ❌ 误区 9：手机顶部的 VPN 图标还亮着，说明当前节点绝对还在正常工作。(错！VPN 图标仅代表本地隧道开启，不代表节点通畅)
 ❌ 误区 10：遇到全红问题，在手机设置里把 IPv6 永久禁用就能彻底根治。(错！规范配置的双栈网络完全不影响节点握手)
 ❌ 误区 11：在电脑上同一个节点能用，手机上全红说明小火箭客户端有 Bug。(错！手机与电脑的本地 DNS、系统时间各异)
 ❌ 误区 12：节点全红是因为手机电量低于 20% 触发了省电模式。(错！省电模式不影响前台测试握手)
 ❌ 误区 13：只要把路由模式切成全局代理 (Proxy)，超时的节点就能自动连上。(错！节点本身连不上，切全局只会全网瘫痪)
 ❌ 误区 14：把包含节点 IP、端口和密码的完整截图发到大群里让网友帮忙看。(错！严重暴露个人专属凭据，极易被盗刷)
 ❌ 误区 15：一个地区节点变红，就代表那个国家的整个互联网都断网了。(错！仅代表机场通往该机房的中转入口发生波动)
```

## 十、常见问题解答 (FAQ)

### Q1：Shadowrocket 节点旁边显示红色的 Timeout 是什么意思？
**答**：Timeout 代表超时。说明小火箭在向该节点服务器发起连接或测速探针时，在预设时间内未收到任何握手响应包。常见原因包括服务器维护、本地网络阻断、DNS 无法解析或系统时间偏差导致 TLS 握手被拒。

### Q2：为什么所有国家的节点在同一时间全部集体标红 Timeout？
**答**：全球不同机房不可能在同一秒内全部瘫痪！全红 100% 是触发了本地公共变量：请优先检查 iPhone 系统时间是否准确（误差超 60 秒会导致 TLS 握手失败）、家庭 Wi-Fi 是否发生 DNS 污染，或机场套餐流量是否已用尽。

### Q3：为什么 Wi-Fi 下测速全红，一旦换成手机 5G 流量就全绿了？
**答**：这说明机场节点完全正常，故障 100% 在家庭 Wi-Fi 上！通常是因为本地宽带运营商对境外代理端口进行了阻断，或家庭路由器分配的 DNS 被污染。在手机 Wi-Fi 设置中将 DNS 手动修改为 `223.5.5.5` 即可解决。

### Q4：为什么连通性测试全红，但我开启连接后依然可以秒开 Google？
**答**：因为小火箭的“连通性测试”只是向特定测试网址（如 Cloudflare 204）发送微型探针；如果该测试网址恰好受阻，就会显示红字 Timeout，但这并不影响节点本身代理其他海外网站的数据转发能力。

### Q5：小火箭列表里显示的毫秒数字（ms）越低，网速就越快吗？
**答**：**绝对不是！** 毫秒数字仅代表握手往返延迟 (Latency)；看 4K 视频和大文件下载主要取决于节点的物理总带宽储备与丢包率。很多 120ms 的专线大水管节点看视频远比 20ms 的拥堵小水管流畅。

### Q6：节点全部超时的时候，应该把订阅删掉重新添加吗？
**答**：**千万不要随意删除！** 节点全红往往只是临时的网络阻断或本地设置偏差；一旦删光旧配置，你将失去现存的所有服务器参数，反而会导致彻底无法联网排查。

### Q7：系统时间误差真的会导致所有节点变红连不上吗？
**答**：是的！新一代翻墙协议（如 VLESS Reality、Trojan 等）内置了严格的“防重放时间戳校验”，系统时间误差超过 60 秒就会被服务端判定为攻击并直接阻断；在手机设置中开启“自动设置时间”即可秒级复活。

### Q8：怎么确认是不是自己的机场流量用光了？
**答**：断开手机代理，使用 Safari 浏览器正常访问机场官网，登录个人中心查看用户仪表盘。若显示剩余流量为 0GB 或套餐已过期，续费后在小火箭中下拉刷新订阅即可恢复。
