> **【💡 30 秒极速直接答案：软件不走代理核心定性与四大排障原则】**
> - **第一核心定性**：**“浏览器能正常看 YouTube，但特定软件（如 Telegram、Git 命令行、Steam 游戏）死活连不上，99% 的情况下节点和网络完全正常，纯粹是因为这些软件在底层调用了裸套接字（Socket），完全不读取操作系统的【系统代理】注册表！”**；
> - **四类最常见软件不走代理极速对号入座**：
>   1. **Telegram (电报) / Discord 桌面端无限转圈** ──► 属于**应用不支持 Windows 注册表代理** ──► 软件设置内手动填 SOCKS5 `127.0.0.1:10808` (v2rayN) 或 `7897` (Clash)；
>   2. **Git clone / pip install / npm 终端报错连接超时** ──► 属于**控制台工具不继承桌面代理** ──► 终端执行 `$env:http_proxy="http://127.0.0.1:端口"` 或开启 TUN 模式；
>   3. **Steam 社区、Apex、CS2 外服网游无法联机** ──► 属于**网游走 UDP 数据包，普通 HTTP 系统代理完全无法转发** ──► 必须在客户端开启**【TUN 虚拟网卡模式】**；
>   4. **在客户端【连接 (Connections)】里看到该软件显示为【Direct (直连)】** ──► 属于**分流规则漏掉了该软件的域名或进程名** ──► 规则中添加 Proxy 或临时切 Global 全局测试。

## 一、常见软件通信机制分类与对代理反应速查总表

在操作系统中，不同软件编写时采用的网络通信库差异极大：

| 应用程序分类 | 网络通信底层机制 | 对 System Proxy 的反应 | 典型软件代表 | 标准解决方案 |
| :--- | :--- | :--- | :--- | :--- |
| **标准桌面浏览器** | 调用系统标准网络栈 (WinINET/WebKit) | 🟢 **100% 自动读取系统代理** | Chrome, Edge, Safari | 保持开启系统代理即可 |
| **独立代理浏览器** | 具备独立网络配置模块 | 🟡 需在浏览器内指定跟随系统 | Mozilla Firefox | 进入设置勾选【使用系统代理】 |
| **大型 3D 联机游戏** | 裸 Socket 套接字通信 (大量使用 UDP) | ❌ **完全无视系统代理** | Steam 游戏, Apex, 瓦罗兰特 | **必须在客户端开启 [TUN 虚拟网卡](/tizi/tun/)** |
| **开发者命令行工具** | 仅读取特定环境变量与独立配置文件 | ❌ **默认不读取操作系统注册表** | Git, CMD, PowerShell, npm, pip | 配置 `HTTP_PROXY` 或开启 TUN |
| **即时通讯/协同软件** | 跨平台 Electron 架构 / 原生 Socket | 🟡 登录走 HTTP，核心数据走 Socket | Telegram, Discord, Spotify | 软件内配置 SOCKS5 或开启 TUN |
| **Linux 子系统/容器** | 独立网络虚拟命名空间 | ❌ **完全独立于宿主机代理** | WSL2, Docker Desktop | 配置镜像代理或 TUN 模式 |

## 三、常用独立软件单独配置代理实战指南

### 1. Telegram (电报) 桌面端配置
- 打开 Telegram 左上角菜单 ──►【Settings (设置)】──►【Advanced (高级)】──►【Connection type (连接类型)】；
- 选择【Use custom proxy (使用自定义代理)】──► 点击【Add proxy】；
- 协议选择 **`SOCKS5`**，主机填 `127.0.0.1`：
  * Clash Verge Rev 用户：端口填 **`7897`**（默认混合端口）；
  * v2rayN 用户：端口填 **`10808`**（默认 SOCKS 端口）；
- 保存后右下角瞬间打勾连接！

### 2. Git 命令行全局绑定代理
在终端中执行以下命令，让 Git 无论在哪个目录都能秒级拉取 GitHub 仓库：
```bash
# Clash Verge 用户配置 (7897 端口)：
git config --global http.proxy http://127.0.0.1:7897
git config --global https.proxy http://127.0.0.1:7897

# v2rayN 用户配置 (10809 端口)：
git config --global http.proxy http://127.0.0.1:10809
git config --global https.proxy http://127.0.0.1:10809

# 取消 Git 代理命令：
git config --global --unset http.proxy
git config --global --unset https.proxy
```

### 3. CMD 与 PowerShell 终端临时环境变量
在当前终端窗口临时赋予代理能力（关闭窗口后自动失效）：
```powershell
# Windows PowerShell 终端中执行：
$env:http_proxy="http://127.0.0.1:7897"
$env:https_proxy="http://127.0.0.1:7897"

# 经典 CMD 命令行中执行：
set http_proxy=http://127.0.0.1:7897
set https_proxy=http://127.0.0.1:7897
```

## 五、分流规则误判排查：在【连接】中显示 Direct 的解决办法

有时候软件已经把流量交给了客户端，但客户端却把它当成“国内直连”放行了：

```text
 1. 【在客户端中实时抓包定位】：
    - 打开 Clash Verge Rev 的【连接 (Connections)】或 v2rayN 的日志；
    - 在目标软件中点击刷新，观察客户端列表中是否刷出了该软件的请求；
    - 查看其匹配规则（Rule）：若显示为 `DIRECT` 或 `MATCH -> DIRECT`，说明被分流规则误判成了国内直连！

 2. 【两步彻底解决】：
    - 【临时验证】：将分流模式切换为 **【Global (全局模式)】**，若软件瞬间恢复正常，100% 证实为规则误判；
    - 【永久添加】：在客户端配置或自定义规则中，添加一行规则：
      * `DOMAIN-SUFFIX,目标域名.com,PROXY` 或 `PROCESS-NAME,软件进程名.exe,PROXY`。
```

## 八、常见问题解答 (FAQ)

### Q1：为什么浏览器看视频非常流畅，但桌面版 Telegram 却一直转圈连不上？
**答**：因为 Windows 的“系统代理”仅适用于标准浏览器，Telegram 等独立应用默认不读取系统注册表代理。**在 Telegram 的网络连接设置中手动添加 SOCKS5 代理（地址 `127.0.0.1`，端口根据客户端填 `7897` 或 `10808`）**即可秒级解决；或者直接开启客户端的【TUN 模式】。

### Q2：为什么 Git 命令行执行 `git clone` 经常报连接超时？
**答**：终端命令行工具（Git/curl/npm）属于跨平台无头工具，默认不继承操作系统的图形界面代理。在终端中执行 `git config --global http.proxy http://127.0.0.1:端口` 赋予全局代理，或者开启客户端的【TUN 虚拟网卡模式】。

### Q3：打外服联机网游（如 Apex、Steam）为什么普通代理没用，必须开 TUN 模式？
**答**：绝大多数联机网游的实时对战数据走的是**无连接的 UDP 协议**；普通系统代理仅支持 HTTP/Web 协议，完全无法转发 UDP；TUN 模式具备驱动级底层捕获能力，能完美转发并加速游戏 UDP 数据流。

### Q4：为什么 Edge 浏览器能翻墙，但主力 Chrome 浏览器却打不开外网？
**答**：这是极其典型的 **Chrome 浏览器插件截胡**！检查 Chrome 右上角是否安装了 SwitchyOmega 等代理插件。一旦安装了这类扩展，操作系统的全局代理会被彻底忽略；在插件菜单中将模式切为【系统代理】即可恢复。

### Q5：如何判断某个软件到底有没有把流量送入代理客户端？
**答**：打开客户端的【连接 (Connections)】或实时日志面板，在目标软件中发起网络请求。如果列表中**完全没有该软件的进程名或目标域名**，说明该软件未接管；如果显示但标记为 `DIRECT`，说明是规则误判。

### Q6：开启 TUN 模式之后，为什么家里的局域网 NAS (192.168.1.x) 打不开了？
**答**：因为局域网私有网段被虚拟网卡错误劫持了。在分流规则中确保包含 `IP-CIDR,192.168.0.0/16,DIRECT` 规则，并确保分流模式处于【Rule 规则模式】即可恢复。

### Q7：什么是混合端口 (Mixed Port)？
**答**：混合端口（如 Clash 的 `7897`）是同时支持 HTTP 代理与 SOCKS5 代理的统一本地端口，无论软件要求填 HTTP 还是 SOCKS5，均可统一填入该端口，大幅简化配置。

### Q8：遇到特定软件不走代理，最忌讳的操作是什么？
**答**：最忌讳“病急乱投医盲目重装系统或重置路由器”。按照“检查软件通信机制 ──► 软件内配端口 ──► 终端配环境变量 ──► 管理员开启 TUN”四步法，任何软件不走代理的难题都能彻底解决。
